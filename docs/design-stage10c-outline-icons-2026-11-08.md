# GalliPick 10-C — 전체 기능 아이콘 아웃라인 통일

기준: 2026-11-08 · 10-B HEAD `dc1d4de9` · 10-A의 Mono Cat 컬러 시스템 · v0.2.8(code 19) 유지

## 적용 범위
- 앱 공통 내비게이션 4개 탭(홈·파일·정리·설정): Material Outlined 아이콘 사용. 기존 `GalliNavigationIcon`의 Rounded→Outlined 임시 치환 분기를 제거하고 호출부부터 아웃라인 벡터를 전달함.
- 파일: 검색/검색 취소, 보기 전환, 필터, 즐겨찾기, 보호, 선택, 상세, 사진/동영상 플레이스홀더, 카메라 줌.
- 정리: 완전 중복 검사, 유사/연속/흐림 분석, 검사 시작/일시정지/재개, 폴더/저장공간, 정리 기록.
- 비교/상세: 남길 항목 고정·잠금, 선택 체크, 파일 열기, 이전/다음 및 닫기.
- 휴지통/복원: 휴지통 이동, 복원, 취소, 상태 안내를 기존 문구와 함께 아웃라인으로 표시.
- 설정/권한/모달: 테마, 미디어 접근, 보호 폴더, 분석 캐시, 날짜 선택, 확인/닫기, 경고/안내 아이콘.
- 18개 UI Kotlin 호출부 `Icons.Rounded` → `Icons.Outlined` 일괄 교체. `BrandAssets.kt`에서 중복 아이콘 패밀리 매핑을 제거하여 공통 컴포넌트가 같은 원본 패밀리를 사용.

## 시각 원칙
- 무채색 `Ink`, `Primary`, `Muted`와 위험 안내에 사용 중인 시맨틱 색은 10-A의 기존 토큰을 유지.
- 새로 배경색 타일/그림자/그라데이션을 추가하지 않음. 아웃라인과 라벨을 함께 써서 보호·선택·삭제 상태를 색만으로 판단하지 않도록 유지.
- 일반 액션은 기존 20~24dp, 작게 표시되는 배지는 기존 14~19dp, 큰 카테고리/안내는 26~30dp의 문맥별 크기를 유지(레이아웃 및 클릭 타깃 변경 없음).
- 10-B의 네 가지 홈용 VectorDrawable과 독립 고양이 헤더 마크, 10-D 대상 일러스트는 그대로 보존. 캐릭터/런처/스토어 아이콘은 이 단계에서 변경하지 않음.

## 동작 안전성
- 아이콘 참조 및 표시 방식 외 미디어 접근 권한, 파일 선택, SHA-256 판정, 정리 후보, 다운로드/날짜 필터, 보호/즐겨찾기, Android 휴지통 승인/복원, 캐시/DB 코드는 수정하지 않음.
- 모든 기존 아이콘 버튼의 텍스트/콘텐츠 설명 및 48dp 터치 영역 유지.
- 하단 파일 탭은 기존 10-B 런타임에 표시되던 PhotoLibrary 윤곽을 직접 사용하여 시각적 연속성을 유지.
- Google Play 배포, 테스트 트랙, 앱 ID, 버전/서명키 변경 없음.

## 검증 게이트
1. `Android verification`: 전체 JVM, Lint, 디버그 빌드 및 릴리스 도구 검사.
2. `Android device tests`: 기기 계측 테스트. `GalliDesignSystemTest`에서 4개 탭의 Outlined 출처, 주요 위험 아이콘의 픽셀 가시성·고유성, 기존 10-A 대비 검증.
3. `ReferenceHomeScreenTest`, `AdaptiveOverviewTest`, `DuplicateClarityTest`, `TrashReviewFlowTest`와 기타 계측 회귀 테스트 보존.
4. **의존 PR #72(10-B) 승인/검증/병합 전에 10-C를 main에 직접 병합하지 않음.** 10-C는 10-B 브랜치를 대상으로 하는 후속 PR로 관리.
5. 실제 5환경 × 라이트/다크 화면 캡처 정밀 검수는 10-E 범위로 별도 진행.
