# GalliPick 원본 시안 정밀 리디자인 — 2단계 내비게이션

- 원본 기준: Google Drive `GalliPick_9screens_design_reference_20261105.png`
- 선행 작업: PR #24의 원본 팔레트/타이포그래피/에셋 시스템
- 이번 변경은 5개 최상위 탭을 **홈·파일·정리·설정 4개 탭**으로 재구성하며, 중복 검사·복원/파일 보호 로직을 삭제하거나 변경하지 않습니다.

## 구현 기준

- 최상위 `Destination`을 4개로 한정하고, `중복`은 `정리` 화면 내부 서브루트로 관리합니다.
- `중복` 하위 화면을 보는 중에도 하단 탭/태블릿 레일에서는 **정리**가 선택된 상태를 유지합니다.
- 중복 진입 시 기존 `AppViewModel.prepareDuplicateReview()`만 실행합니다.
- 다른 탭이나 파일 검색 결과로 이동하면 중복 하위 화면 상태를 초기화합니다.
- 시스템 Back과 명시적 뒤로 버튼의 복귀 목적지는 정리이며, 홈 바로가기에서도 동일합니다.
- `정리` 메인에서 중복 검사 진입 카드는 48dp 이상 터치 영역과 명시적 접근성 이름을 제공합니다.
- 휴대폰 하단 메뉴, 태블릿 왼쪽 레일, 휴대폰 가로/큰 글씨가 같은 4개 목적지를 사용합니다.
- `ScrollAwayHeaderLayout`의 화면 변경 키에 중복 하위 루트 상태를 포함해 스크롤/헤더 위치를 복구합니다.
- 원본 9개 시안에 없는 유사 사진 판정, 자동 삭제, 예상 절약 용량은 추가하지 않습니다.

## 검증

- `AdaptiveNavigationTest`: 4개 탭, 48dp 터치 영역, 작은 가로/큰 글씨 레일
- `GalliDesignSystemTest`: 다크 모드/라이트 모드 아이콘과 4개 탭 접근성
- `ReferenceNavigationFlowTest`: 홈·정리에서 중복 하위 진입, 시스템 Back, 다른 탭 전환 복원
- `NativeScreenCaptureTest`: 실제 4탭 안에서 중복 진입·스캔·비교·Back을 거친 11장 화면 캡처
- 휴대폰 세로·가로·글씨 160%, 태블릿 세로·가로의 전체 UI 검증
- 기존 SHA-256 중복 검사·파일 선택·보호·휴지통 승인 테스트를 회귀 검사
