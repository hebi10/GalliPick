# GalliPick 7-E — 파일 상세·미리보기·휴지통 정밀 보정

기준: 원본 9화면 디자인 시안 및 7단계 원본-실제 비교 기획서. 선행 PR #34(7-D)가 2026-11-06 검증·병합 완료된 main 커밋 3db4b145670bb39a08f03873bb3dd6d504c100fc 기준.

## 변경 이유 및 범위

### M-01~M-03 파일 상세·미리보기
- 기존 모달 실캡처의 사진 상세에는 자리표시가 남아 있었습니다. 정상 사진은 기존 decodePreviewBitmap으로 MediaStore 원본을 제한된 크기로 직접 디코딩하고 ContentScale.Fit으로 표시합니다. 실패 시 명시적인 안내/다시 시도를 제공하며 일반 파일 갤러리의 Crop 썸네일 방식은 변경하지 않습니다. 동영상 상세는 기존 MediaStore 썸네일 경로를 유지합니다.
- 가로 공간이 충분할 때 '파일 열기'와 '보호' 버튼을 두 칸으로 배치하고, 글꼴 160% 또는 좁은 화면은 기존 세로 버튼을 유지합니다. 사진 확대/동영상 재생은 별도 '앱에서 미리보기' 경로를 유지합니다.
- 메타데이터의 라벨/값을 행 단위로 정렬해 동일 정보(촬영일 또는 저장일·용량·해상도·파일 형식·폴더·추가/수정일)를 더 적은 세로 공간에서 확인하도록 개선합니다.
- 로딩/오류에서 보여주는 기존 축소 미리보기 자리표시 및 별도 오류 재시도 정책은 유지합니다. 미디어가 없을 때 정상 이미지인 척 표시하지 않습니다.

### T-01~T-03 휴지통
- 76dp 썸네일을 56dp로 줄이고 행 패딩·간격을 압축합니다. 체크박스는 48dp를 유지하며 복원 대상, 용량, 파일명, 폴더/보호 상태 표시를 유지합니다.
- 휴지통 설명은 Android 보관 기간과 시스템 복원 승인을 간결하게 안내합니다. 선택 합산과 복원 요청 버튼은 그대로 고정하며 실제 용량 확보로 오해하게 하지 않습니다.
- 계측 캡처 fixture에서 정상 디코딩되는 사진 11개를 휴지통 목록에 표시하여 단일 예시의 과도한 공백을 기준으로 판단하지 않도록 합니다. 실제 시스템 휴지통 이동은 실행하지 않으며 모든 fixture는 종료 시 제거합니다.

## 검증 및 안전 정책
1. Android verification: assemble, unit, Lint 통과.
2. Android device tests: 420dp 기본 글꼴에서는 파일 열기/보호가 한 행, 320dp + 160%에서는 세로 배치; 메타데이터 접근; 기존 미리보기 확대·파일 열기·보호 동작 및 500개 복원 제한 회귀.
3. Adaptive UI verification and native captures: 휴대폰 세로/가로/글꼴 160%, 태블릿 세로/가로의 네이티브 14개 기본·12개 모달/상세 캡처 성공. 특히 03-file-detail과 09-trash-list를 원본 시안과 비교.
4. Android MediaStore 실제 사진/영상 디코딩, 실패 시 재시도, 시스템 승인·취소, 보호·즐겨찾기 파일 제외 정책 보존.
5. 위 검증 결과와 실제 캡처 검수 후에만 main 병합.
6. versionName/versionCode, Play 트랙·배포 트리거, 앱 ID, 서명키는 변경하지 않습니다.

## 추가 검증 필요
