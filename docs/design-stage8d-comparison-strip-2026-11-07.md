# GalliPick 8-D — 전체 파일 가로 비교 목록

2026-11-07. 선행 8-C PR #47 검증 및 병합 후 최종 재검증.

## UI 구조
- 기존 좁은 화면 A/B 탭 및 큰 화면 2패널을 폐기하고, 상단 전체 사본을 `LazyRow`로 나열합니다.
- 첫 칸은 항상 추천/직접 지정한 남길 파일. 보호/즐겨찾기 파일은 별도 남김 상태로 구분합니다.
- URI 키의 카드 탭은 '현재 보고 있는 파일'만 바꿉니다. 아무 파일도 삭제/선택하지 않습니다.
- 명시적 '이 파일 남기기'로만 기존 `chooseDuplicateKeeper`를 호출해 keeper를 변경합니다. 새 keeper는 0번 위치로 이동합니다.
- 아래에는 선택한 단 하나의 실제 미디어/상세를 렌더링합니다. 파일 이름·경로·용량·해상도·길이·촬영/추가일·보호·휴지통 후보 선택을 보존합니다.
- 미디어 변경 시 이전 동영상 재생을 정지하며, 비교 종료 시에도 `PreviewPlaybackCoordinator`를 중지합니다.
- Android 시스템 휴지통 이동은 기존 메인 화면의 별도 최종 승인 경로로만 진행합니다.
