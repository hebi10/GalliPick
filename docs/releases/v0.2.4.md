# GalliPick v0.2.4 — 비공개 테스트 alpha

- 패키지: `com.hebi.gallipick`
- versionName: `0.2.4`
- versionCode: `15` (기존 v0.2.3/code 14보다 증가)
- 대상: 기존 Google Play 비공개 테스트 `PLAY_CLOSED_TRACK=alpha` **하나만**
- 릴리스 기준: 7-E 병합 완료 `main` `b455633943f6464d979318fbfa82e70816b491e4`
- 릴리스 대상: 7-B~7-E 실제 Android 화면 정밀 개선. 7-A 샘플 미디어는 androidTest 검증 fixture로만 포함되며 일반 사용자의 기기에 생성하지 않음.
- 7-B: 홈 히어로·대표 버튼·빠른 실행 반응형 보정 (PR #32)
- 7-C: 파일 목록의 전체/사진/동영상 및 필터·정렬 도구 배치 보정 (PR #33)
- 7-D: 중복 파일 묶음 밀도·대표 미리보기, A/B 비교 파일명 표시 (PR #34)
- 7-E: 파일 상세 실제 JPEG 표시·오류 재시도, 버튼/메타데이터 배치, 휴지통 목록 밀도 (PR #35)
- 보존: 홈·파일·정리·설정 4탭, SHA-256 완전 일치, 보호/즐겨찾기·남길 파일 제외, Android 시스템 휴지통 승인·복원, 기존 업로드 키와 고정 서명 인증서
- 변경 금지: 내부 테스트/프로덕션/기타 트랙, 앱 ID, 서명, 스토어 등록정보·테스터 구성
- 릴리스 노트: `docs/play-store/release-notes-ko.txt`
- 자동 제출: 단독 **`[deploy-closed]`** 마커를 포함한 `main` 병합 커밋. `[deploy-internal]` 마커 사용 금지, 버전 태그 push 금지
- 확인 항목: Android verification, Android device tests, 고정 서명 및 Play preflight, signed APK/AAB, Play 제출 보고서의 `track=alpha`, `status=committed`, `api_accepted=true`, `track_verified=true`, `version_code=15`
- Google Play API 제출과 실제 심사 통과 및 테스터 제공 상태는 별개. Play Console에서 후속 확인.
- 중요: 제출 실패/응답 불명 시 바로 재제출하지 않고 Google Play 트랙 및 보고서로 중복 업로드 여부를 확인.
