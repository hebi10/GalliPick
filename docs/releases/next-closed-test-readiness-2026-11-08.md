# GalliPick 차기 비공개 테스트 출시 준비 점검표

기준일: 2026-11-08 / 기준 main: PR #66 병합 SHA 346df7f3f403a08b2938fbe76b3b7bbbae36da54

## 릴리스 후보
- 제안: 0.2.8 (code 19). 이는 확정 버전이 아니라 새 Android AAB 업로드 전에 검증할 후보입니다.
- 기존 비공개 테스트: 0.2.7 (code 18) 배포 기록 확인. 신규 기능 9-A~9-G는 아직 해당 버전 AAB에 실리지 않았습니다.
- 신규 제출 시 기존 고정 서명 인증서 유지. 같은 code 18 재업로드 금지.
- 사용자가 명시적으로 요청하기 전까지 테스트 트랙, 생산용 앱, 버전 코드를 변경하지 않습니다.

## 우선 검사
1. Android verification, Android device tests: 마지막 기능 코드 HEAD와 merge된 main 모두 성공.
2. 전체 화면: 5환경별 45장(실제 MainActivity 17, Compose 모달 16, 기능 fixture 12) + 폴더 화면 1장, 총 230장. 스크린샷 픽셀 구조뿐 아니라 눈으로도 빈 화면·오버랩 확인.
3. 삼성 실기기에서 사진 접근(전체/일부/없음), 백그라운드 분석, 1천개 이상 미디어, 디코드 실패·HEIC, Android 휴지통 승인과 복원, 기기 발열/메모리 확인.
4. Room 실제 업그레이드: v3→v4→v5 및 이전 보호 설정과 기존 로컬 미디어 캐시가 보존되는지 검증.
5. Google Play 서비스 계정/고정 키/정확한 기존 alpha 트랙 검증. 새로운 code 19가 업로드되지 않았는지 확인한 후, 서명된 AAB 생성 및 API 조회.
6. Play 사진·동영상 권한 선언: 앱의 핵심 기능인 전체 라이브러리 탐색·중복 판별을 대체 수단으로 구현할 수 없는 이유를 최신 기능 기준으로 점검.
7. Play 데이터 보안·개인정보처리방침 동기화. pHash/선명도/정리 기록은 기기 내 저장, 서버 전송 없음. 앱이나 외부 SDK에서 자동 데이터 전송이 추가되지 않았는지 병합 Manifest·정적 분석 확인.
8. 한국어 스토어 문구는 유사 사진 분석과 정리 기록을 설명하도록 갱신. 등록된 설명 이미지 8장·대표 그래픽 1장은 0.2.7 기능 기준이므로 신규 기능 표시 여부를 먼저 검수.
9. 프로덕션 공개는 별도 정책·비공개 테스트 요건·출시 승인 이후에만 수행. 내부/비공개 테스트 API commit은 심사 승인 및 테스터 제공과 구분.
