# GalliPick v0.2.8 (versionCode 19) — 비공개 테스트 alpha

## 범위

- 앱 패키지: `com.hebi.gallipick`
- 신규 소스 버전: `versionName=0.2.8`, `versionCode=19`
- 기존 Play 비공개 테스트: `0.2.7 (code 18)`. 새 버전은 실제 Google Play 전체 트랙·라이브러리에서 code 19 미사용 여부를 검증한 후에만 제출합니다.
- 제출 대상: 기존 `PLAY_CLOSED_TRACK`으로 식별된 비공개 테스트 `alpha` **한 곳**. 내부 테스트, 공개 테스트, 프로덕션 등 다른 트랙은 변경하지 않습니다.
- 대상 GitHub: 현재 `main`에 병합된 9-A~9-G 기능과 개선 사항.

## 새 기능

1. 정리 탭 구성·폴더별 저장 공간 분석.
2. 기기 내부 pHash 기반 유사 사진 후보 분석·비교 및 연속 촬영 사진 그룹.
3. 선명도가 낮을 수 있는 사진을 **추정치**로 표시해 사용자 검토 지원. 화질 확정 판정이나 자동 삭제를 하지 않습니다.
4. Android에서 처리 여부를 재확인한 휴지통 이동·복원 작업의 로컬 정리 기록 저장·조회·기록만 삭제.
5. 9-G: 5개 환경의 실제 Android UI 캡처와 회귀 검사, 큰 글씨·화면 안전 영역 개선, 캡처의 빈 화면 자동 검증.

## 안전 및 검증

- 기기 데이터와 로컬 분석 캐시·보호 설정을 기존 방식으로 보존. 분석 수치·정리 이력을 외부 서버로 보내지 않습니다.
- Android 휴지통 이동·복원은 사용자가 확인하고 Android 시스템에서 승인. 영구 삭제 기능을 추가하지 않습니다.
- 서명 검증은 기존 `GALLIPICK_SIGNING_BUNDLE_BASE64`와 고정 인증서 SHA-256을 재사용하며 비밀값을 저장소에 기록하지 않습니다.
- 자동 Play 배포는 `[deploy-closed]`가 붙은 **버전 코드 증가가 확인된** `main` 커밋에서만 시작하며, 모든 트랙·AAB·APK의 기존 버전 코드와 대상 비공개 테스트 트랙 상태를 확인한 후 제출합니다.
- `Play testing deployment`는 해당 릴리스 소스의 Android verification·device tests, 고정 서명키, signed APK/AAB 검증과 Play API 제출·별도 편집 재조회를 수행합니다.
- 외부 Gradle/bundletool 다운로드 오류는 릴리스 실패이며, 검증을 우회하지 않습니다.
- Play API `commit` 수락과 실제 Google Play 심사 승인·테스터 설치 가능 여부는 별도로 판정합니다.
- 실제 삼성 기기에서 일부 미디어 접근, 휴지통 이동·복원, 데이터 업그레이드·대용량 성능 검증은 후속 사용자 설치 QA가 필요합니다.

## 성공 조건

1. `status=committed`, `api_accepted=true`, `track_verified=true`, `track=alpha`.
2. `version_code=19`, `version_name=0.2.8`, `com.hebi.gallipick` 명시.
3. 새 편집에서 alpha 트랙의 새 versionCode를 다시 확인.
4. Google Play Console 심사/게시 상태와 실제 테스트 설치 가능 여부는 별도 확인.
