# GalliPick v0.2.0 — 디자인 리디자인 완료 / 내부 테스트

- 버전: `0.2.0` / Android `versionCode 11`
- 패키지: `com.hebi.gallipick`
- 목표 트랙: Google Play `internal` 단독
- 기능 변경 범위: 1~6단계의 UI 및 접근성 개선, 기존 파일 처리·중복 정책 보존
- 업로드 키: 기존 고정 키 사용. 새 키 발급 및 교체 금지
- 앱 최소 지원: Android 11 (API 30), 타깃 API 36

## 포함 사항

- 홈 대시보드, 파일 목록, 필터, 중복 검사·비교, 정리 후보, 파일 상세·미리보기·휴지통, 설정 전면 개선
- Android 승인 및 MediaStore 상태 확인을 기준으로 정리 성공·부분 성공·취소·오류·확인 불가 표시
- 권한 없음·로딩·오류·빈 결과 화면의 반응형 동작 및 접근성 제목, 48dp 파일 선택 터치 영역
- 휴대폰 세로/가로/큰 글씨 160% 및 태블릿 세로/가로 5개 환경 회귀 검증
- 실제 Android UI 캡처 기반 7개 한국어 스토어 이미지(1350×2400 RGB PNG) 및 1개 피처 그래픽(1024×500)
- 스토어 에셋 출처: [최종 Android 캡처 실행 #42009167309](https://github.com/hebi10/GalliPick/actions/runs/42009167309), 소스 커밋 `1a5f61b7b0e6d2f217f793ac31a60654180b24f4`
- 스토어 에셋 재생성: [GitHub Actions 실행 #42012102044](https://github.com/hebi10/GalliPick/actions/runs/42012102044)
- SHA-256 이미지 검증: `assets/play-store/ko-KR/manifest.json`

## 릴리스 안전장치

1. `main`에 `app/build.gradle.kts`의 `versionCode 10 → 11` 변경을 병합한 경우에만 새로운 내부 테스트 릴리스 시작
2. PR 병합 메시지에 `[deploy-internal]`을 명시하여 GitHub Actions `Play testing deployment`의 배포 조건 충족
3. `scripts/release/signing_bundle.py`로 기존 서명키를 GitHub Actions 비공개 환경에서 복원하고 `app:verifyGalliPickSigning` 검증
4. 기존 키 서명 APK/AAB 생성, APK/AAB 메타데이터·SHA-256·매니페스트·서명 검증, Android 단위·기기 테스트 통과 후 API 제출
5. Google Play API 요청 대상은 `internal`만 사용. `closed`, `production` 변경 금지
6. 스토어 이미지 편집과 내부 테스트 릴리스 API 편집을 동일한 GitHub Actions 동시성 그룹으로 순차 실행
7. API 성공·릴리스 게시·테스터 실제 설치 가능 여부는 독립적으로 판정. 사용자 요청에 따라 이 작업에서 Play Console 실제 게시 여부는 별도 확인하지 않음
