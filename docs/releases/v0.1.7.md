# GalliPick 0.1.7

- 중복 파일의 남김·정리 후보 표시와 전체·묶음 선택 범위를 명확하게 정리했습니다.
- 휴대폰 가로 화면에서 남길 파일과 정리 후보를 나란히 확인할 수 있습니다.
- 비교 화면의 파일 선택·남길 파일 지정·보호 동작을 구분하고 날짜 근거를 표시합니다.
- 필터 입력란과 적용 버튼이 키보드에 가려지는 문제를 개선했습니다.
- 태블릿 파일 목록의 빈 상세 영역을 없애고 홈·정리·설정 배치를 개선했습니다.
- 큰 글자와 짧은 창에서도 주요 동작에 접근할 수 있도록 조정했습니다.
