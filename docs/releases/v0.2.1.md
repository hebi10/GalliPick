# GalliPick v0.2.1 — 하단 탭 시각 오류 수정 및 스토어 이미지 재구성

- 앱: `com.hebi.gallipick`
- 버전: `0.2.1`, `versionCode 12`
- 변경 범위: 디자인/스토어 캡처 검수 보완. 중복 검증·휴지통 승인·보호 정책·데이터 처리 로직 변경 없음
- Google Play 목표 트랙: `internal`만 사용. 비공개 테스트·프로덕션 자동 변경 금지

## 실제 Android 캡처에서 발견한 문제

- 기존 다크 모드의 하단 `홈·파일·중복·정리·설정` 이미지가 단색 사각형으로 표시됨
- 원인: 배경이 불투명한 내비게이션·유틸리티 PNG 전체에 `ColorFilter.tint`를 적용하면서 그림 부분의 형태가 사라짐
- 수정: 라이트 모드는 기존 브랜드 일러스트 PNG 유지. 다크 모드는 배경 없는 Material 벡터 아이콘과 현재 팔레트의 대비 색상 사용
- 공통 `GalliIcon`도 다크/색상 변경 시 벡터를 사용하여 설정 카드 등 같은 결함 예방

## 실제 화면 기반 스토어 이미지 개선

- 다섯 주요 메뉴를 첫 다섯 장에 배치:
  1. `01-home.png` — 홈
  2. `02-files.png` — 파일
  3. `03-duplicates.png` — 중복
  4. `04-cleanup.png` — 정리
  5. `05-settings-dark.png` — 설정·다크 모드
- 두 가지 상세 기능:
  6. `06-filters.png` — 실제 필터 모달
  7. `07-comparison.png` — 실제 중복 비교 화면
- 각 파일은 1350×2400 픽셀의 RGB PNG이며, Android의 실제 UI 화면 부분을 변경하지 않고 크림 배경·캡션과 함께 배치한 스토어용 이미지
- 첫 다섯 장의 하단 5개 탐색 아이콘/텍스트 표시 확인. 모달·비교는 일부 탭을 가리는 실제 동작 그대로 유지
- AI로 생성된 디자인 검토 시안이나 구현되지 않은 화면은 실제 Play 스토어 업로드에 사용하지 않음
- 기능 그래픽(1024×500 RGB PNG)은 기존 검증된 GalliPick 고양이 캐릭터 그래픽 유지

## 자동 내부 테스트 업로드 기준

- `app/build.gradle.kts` 버전 변경은 `versionCode 11 → 12`로 증가
- PR의 Android verification, Android device tests 성공 후에만 `main` 병합
- 병합 커밋 제목에 `[deploy-internal]` 사용하여 기존 GitHub Actions의 내부 테스트 자동 배포 활성화
- 기존 업로드 서명키/인증 정보 사용. 새 키 발급·교체 및 외부 유출 금지
- 스토어 이미지 업데이트와 내부 테스트 AAB 업로드는 기존 공통 GitHub Actions 동시성 그룹에서 순차 처리
- GitHub Actions 성공과 Google Play 실제 게시/테스터 이용 가능 여부는 구분. 사용자의 이전 요청에 따라 Play Console 실제 게시 여부는 이 작업 범위에서 확인하지 않음
