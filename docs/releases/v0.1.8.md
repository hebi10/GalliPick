# GalliPick 0.1.8

- 기존 0.1.7의 기능과 화면 개선을 그대로 유지합니다.
- 기존 업로드키의 서명 연결과 GitHub Actions의 APK·AAB 빌드 및 테스트 배포 설정을 정비했습니다.
- 자동 배포는 내부 테스트를 기본으로 사용하며, 비공개 테스트는 수동 실행에서 선택합니다.

앱 기능과 화면은 0.1.7과 동일합니다. 0.1.6에서 업데이트하는 경우 [0.1.7의 개선 사항](v0.1.7.md)도 포함됩니다.

패키지 `com.hebi.gallipick`, versionCode 9. 기존 고정 업로드 인증서를 유지합니다.
Play 업로드 수락·릴리스 상태는 검증 기록에서 별도로 확인합니다.
