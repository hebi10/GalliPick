# GalliPick v0.2.18 (versionCode 29) — 내부 테스트 배포 준비

## 대상 코드 및 기능

대상은 `com.hebi.gallipick`의 기존 Google Play `internal` 테스트 트랙입니다. 최신 `main`에 병합된 파일 탐색/필터/상세 보기 개선 PR #129, 유사 사진 검증 조회 PR #132, 합성 SQLite 측정 PR #133, DB 증분 동기화 PR #134, CI 경량화 PR #135를 포함한 버전입니다.

파일 탭의 전체·사진·동영상 유형 및 기기·클라우드 필터, 그리드·목록·상세 화면을 중심으로 UI 및 안정성 검증을 수행합니다. 유사 사진 생존 사본 pHash 검증, 사진·영상 목록 증분 갱신은 기존 파일 삭제/복원 안전 규칙을 유지해야 합니다.

기존 `v0.2.17 (code 28)` 서명 AAB는 앞선 `main`에서 내부 테스트에 게시됐으므로 새 파일 탭 개선 코드를 포함하지 않습니다. 이 버전은 `0.2.18 (code 29)` 후보이며 Play Console에서 실제 기존 최고 versionCode가 29보다 낮은지 별도 확인한 후 확정합니다.

## Google 로그인 수정

Play 서명에 등록된 Android OAuth와 같은 프로젝트의 웹 OAuth를 Credential Manager에 전달합니다. 계정 인증과 구독 함수 호출은 `gallipick-production`으로 처리합니다. 운영 Firebase Authentication에 해당 웹 클라이언트가 허용되어 있어야 합니다. 빌드는 프로젝트, 패키지, Play 서명과 지정된 두 OAuth 클라이언트의 정합성을 검사합니다. 로그인 오류 화면은 Google 계정 확인 실패와 Firebase 인증 실패를 구분합니다.

## 안전한 배포 선행 조건

- 모든 확정 개발 PR이 최종 `main`에 병합되어 있어야 하며, 최신 정확한 `main` SHA의 Android verification(JVM 단위 테스트·Lint·디버그 빌드), Android device tests(API 36) 및 OPS-08 정책 검사가 모두 성공해야 합니다.
- PR 검사는 경량화하되 `main` 병합 후 에뮬레이터 전체 검사는 유지합니다. 실기기 성능·OEM 호환성은 사용자 사정으로 직접 검증할 수 없으므로 별도 미검증으로 표시합니다.
- 광고 제거·클라우드가 포함된 배포일 경우 승인된 Firebase `production` 환경, Play 서명 SHA-1 및 허용 OAuth 클라이언트, 검증 Functions/RTDN과 Play 구독 기본 요금제의 실제 상태를 확인합니다. Google 로그인·구독/복원/환불의 실제 구매 성공은 자동 테스트만으로 증명할 수 없습니다.
- `versionCode`와 앱 패키지, 업로드 서명 인증서, 정확한 `main` SHA, AAB SHA-256, 비공개 설정·구독 상품을 OPS-03 빌드·OPS-04 `check`에서 재검증합니다.
- 승인 없는 Play 업로드는 하지 않습니다. **OPS-03 서명 AAB 빌드 승인 → 빌드 증거 확인 → 별도 OPS-04 `publish` 승인** 순서로 진행합니다. 기존 AAB를 새로운 `main` 빌드로 표시하지 않습니다.

## 확인해야 할 시나리오

1. 파일 탭에서 사진/영상, 전체/기기/클라우드, 날짜·정렬·그룹 필터가 올바르게 작동하고 검색/필터 닫기 버튼은 작은 화면에서도 접근 가능합니다.
2. 목록/그리드/상세/비교를 반복 이동할 때 기존 선택·화면 상태가 유지되며 원본·휴지통 작업은 Android 사용자 승인을 받습니다.
3. 미디어 접근 허용·일부 허용·철회/복원, 파일 변경, 볼륨 세대 변경 시 오래된 SHA-256·pHash·OCR 원본 증거를 잘못 사용하지 않습니다.
4. 운영 Firebase 연결, 로그인, 광고 제거 월간/연간 구독·복원 및 구독 중 광고 비노출을 **실제 라이선스 테스터가 추후 확인**해야 합니다.
