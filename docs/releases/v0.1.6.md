## 중복 파일 정리

- 중복 묶음에서 남길 파일과 정리 후보를 나눠 표시합니다. 선택된 후보는 이동 대상으로 구분하며 남길 파일·보호·즐겨찾기에는 선택 상자를 표시하지 않습니다.
- 후보 선택 버튼에 대상 개수와 선택 범위를 표시합니다. 묶음별 선택과 결과 전체 선택을 구별하고, 한 번에 최대 500개를 선택합니다.
- 남길 파일 변경 시 해당 묶음의 선택만 초기화하고 다른 묶음의 선택은 유지합니다. 이전에 남기던 파일은 자동으로 이동 대상이 되지 않습니다.
- 비교 화면에서 남길 파일·정리 후보·선택 상태와 전체 이름·폴더·길이·용량을 확인할 수 있습니다. 휴대폰과 태블릿의 창 크기에 맞춰 A/B 전환 또는 나란히 비교합니다.
- 선택한 파일의 수와 용량을 확인한 뒤 휴지통 이동을 요청합니다. 실제 이동에는 Android 승인창의 확인이 필요합니다.

## 설치와 업데이트

- Android 11 이상을 지원합니다. 파일은 `GalliPick-v0.1.6-release.apk`이며 `SHA256SUMS`로 다운로드 파일을 확인할 수 있습니다.
- v0.1.5와 같은 앱 전용 서명 키와 `com.hebi.gallipick` 패키지를 사용합니다. v0.1.5에서 업데이트하는 경우 앱 설정을 유지하는 경로입니다.
- 이전의 다른 키로 서명된 개발 APK는 이번 APK로 덮어쓸 수 없습니다. 이 경우 한 번 삭제 후 재설치해야 하며 앱의 필터·보호·분석 설정이 초기화됩니다. 별도 preview 앱의 설정은 자동 이전되지 않습니다.
- 사진·영상 내용 전체가 같은 사본을 찾는 기능입니다. 유사 사진·영상 판정이나 화질·원본 추정은 포함하지 않습니다. 휴지통 이동만으로 저장 공간이 즉시 확보되지 않을 수 있습니다.

## 검증

이 릴리스는 같은 소스 커밋의 단위 검사·lint·Android 16/API 36 기기 검사를 통과한 후 고정 서명으로 빌드하도록 구성했습니다. 게시 전 APK의 패키지·버전·서명 지문을 확인하고, 초안에 올린 APK를 다시 내려받아 체크섬을 비교합니다. 실제 검사 수와 추가 로컬 확인 범위는 저장소의 `docs/verification.md` 및 연결된 GitHub Actions 실행에서 확인합니다.
