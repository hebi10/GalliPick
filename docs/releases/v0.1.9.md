# GalliPick 0.1.9

- 홈·파일 탐색·중복 검사·정리 후보·설정 및 상세·모달 화면의 공통 디자인을 정리했습니다.
- 앱 아이콘과 테마 아이콘을 초록 모자를 쓴 고양이 캐릭터로 통일했습니다.
- 날짜 필터에서 달력·직접 입력·최근 7일·30일을 지원하고, 가로로 짧은 화면은 간결한 입력 모드를 사용합니다.
- 파일 상세 보호 안내, 미리보기 조작 및 휴지통 이동·복원 전 썸네일·용량·상태 정보를 개선했습니다.
- 기존 SHA-256 완전 일치 중복 검사, Android 시스템 승인 및 기기 내 분석 정책은 유지합니다.

패키지: `com.hebi.gallipick` · 버전: `0.1.9` · versionCode: `10`.

자동 배포는 [Play testing deployment](../../.github/workflows/play-deploy.yml)의 `internal` 트랙에만 제출되며, Google Play API 수락·검토·테스터 제공 상태는 각각 별도로 확인합니다. 기존 업로드키를 재사용하고 비공개 테스트·프로덕션 트랙은 변경하지 않습니다.
