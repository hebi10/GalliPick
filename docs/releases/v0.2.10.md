# GalliPick v0.2.10 (versionCode 21) — 비공개 테스트 alpha

## 릴리스 대상
- 앱 패키지: `com.hebi.gallipick`
- Google Play 트랙: 기존 비공개 테스트 `alpha` **하나만**
- 버전: `versionName=0.2.10`, `versionCode=21` (Play 전체 트랙에서 미사용 확인 후 제출)
- 기존 서명키·인증서·앱 ID 및 사용자 데이터 업데이트 호환성 유지
- 내부 테스트·프로덕션·공개 테스트, 테스터 목록·스토어 이미지·아이콘·권한 선언 불변

## 업데이트 내용
1. **12-A**: 비슷한 사진 A/B 동시 비교 및 동기화된 확대·분할 슬라이더.
2. **12-B**: 선명도·해상도·노출 참고값으로 베스트 컷을 보수적으로 추천. 애매하면 판단 보류.
3. **12-C**: 남김·정리 후보·검토 보류, 진행률, 재실행 후 이어보기를 지원하는 스마트 정리 검토함.
4. **13-A**: 사용자 선택으로 한국어·영문 ML Kit 로컬 OCR 분석. 파일 탭의 검색 범위 전환, 결과 글자·상세 표시, 중단·재개, 색인 초기화.
5. 모바일 가로·글꼴 160%, 태블릿 라이트·다크 반응형 회귀 보정.

## 안전 정책
- OCR 텍스트·사진은 GalliPick 서버에 업로드하지 않고 기기에만 저장한다.
- 사진 수정·권한 철회·파일 지문/볼륨 버전 변경 시 이전 OCR 색인은 검색에서 제외한다.
- **자동 삭제·원본 영구 삭제를 하지 않는다.** 보호·즐겨찾기 및 최소 한 장 보존을 유지한다.
- 사용자가 정리 후보를 명시적으로 선택하고 Android 시스템 휴지통 이동을 승인해야 한다.
