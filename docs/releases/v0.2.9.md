# GalliPick v0.2.9 (versionCode 20) — 비공개 테스트 alpha

## 배포 범위

- 패키지: `com.hebi.gallipick`
- 버전: `versionName=0.2.9`, `versionCode=20`
- 기준 소스: Mono Cat 10-A~10-F가 병합된 `main` (PR #71~#76)
- 제출 대상: 이미 존재하는 Google Play 비공개 테스트 트랙 `alpha`만
- 내부 테스트, 공개 테스트, 프로덕션, 테스터 명단 및 스토어 등록 정보는 변경하지 않음

## 주요 변경

1. 10-A: 기존 아이보리·민트·녹색 중심 화면을 중성 화이트·차콜 라이트/다크 테마로 개편.
2. 10-B: 홈 바로가기 4개와 고양이 브랜드 마크를 분리하고 평면형 자산으로 교체.
3. 10-C: 탐색·선택·보호·정리 등 일반 기능 아이콘의 아웃라인 계열 통일.
4. 10-D: 고양이 상태 일러스트의 중성 테마 자산과 다크 전용 대비 변형 도입, 이전 원본 유지.
5. 10-E: 5개 화면 프로필 × 라이트·다크 전체 Android 캡처 검증 및 시각 감사.
6. 10-F: 태블릿 홈 대시보드의 너비·영역 배치·바로가기 정보 밀도 보정, 기존 기능 및 휴대폰 화면 유지.

## 기능·안전 정책

- 기존 미디어 선택, 중복·유사 사진 분석, 보호·즐겨찾기, 정리 기록과 휴지통 이동·복원 기능 유지.
- 자동 삭제와 영구 삭제 기능을 추가하지 않음. Android 확인 및 복원 정책 변경 없음.
- 기존 동일 업로드 서명키/인증서와 앱 패키지 ID를 유지.
- 스토어 이미지·앱 아이콘·권한 선언·Play 서명 설정을 이번 릴리스에서 수정하지 않음.

## 배포 전 안전 게이트

1. 신규 `versionCode 20`이 Play 전체 트랙·업로드 라이브러리에서 사용되지 않았는지 API로 검사.
2. 대상 비공개 트랙 `alpha`가 존재하고 배포 권한·정책 상태가 유효한지 검사.
3. PR 동일 HEAD의 Android verification 및 Android device tests 통과 확인.
4. `main` squash 병합 메시지에 단독 `[deploy-closed]` 마커를 포함해 기존 Play testing deployment 실행.
5. 릴리스 빌드에서 고정 서명키, 서명 APK·AAB 버전/해시, release 테스트·Lint를 검증.
6. 최종 제출 API 결과와 새로운 edit의 대상 트랙 재조회까지 확인. 충돌·인증 실패·중복 코드 시 자동 재업로드 금지.

## 성공 판정

- 배포 보고서 `status=committed`, `api_accepted=true`, `track_verified=true`, `track=alpha`.
- `version_name=0.2.9`, `version_code=20`, `package=com.hebi.gallipick` 일치.
- API 수락은 Google 검토 승인·비공개 테스터 설치 가능 확인과 다름.
