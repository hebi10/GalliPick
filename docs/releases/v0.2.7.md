# GalliPick v0.2.7 (versionCode 18) — 비공개 테스트 alpha

## 대상 및 변경

- 패키지: `com.hebi.gallipick`
- `versionName=0.2.7`, `versionCode=18` (v0.2.6/code17에서 증가)
- 배포 대상: 이미 존재하는 비공개 테스트 `alpha` 트랙 한 곳만. 내부 테스트·공개 테스트·프로덕션은 변경하지 않습니다.
- 범위: PR #55(고정하지 않은 중복 묶음 카드의 고정 아이콘 제거), PR #56(정리 탭의 비상호작용 안내 카드 제거), PR #57(1년 이전 다운로드 파일·날짜별 묶음·10MiB 이상 사진).
- 날짜 의미: 다운로드 정리의 1년 이전 기준은 파일 **기기 추가일**이며 실제 촬영일·다운로드 완료 시각이라는 뜻이 아닙니다. `Download/`·`Downloads/`과 그 하위 경로의 Android MediaStore가 접근 가능한 사진·영상에만 적용합니다.
- 정리 결과는 기존 파일 목록으로 이동하여 사용자가 직접 선택합니다. 자동 삭제하지 않으며 즐겨찾기·보호 파일 및 Android 시스템 휴지통 승인 정책은 유지합니다.
