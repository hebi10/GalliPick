# GalliPick 9-B · 로컬 유사 사진 분석 기반

- 기준: GalliPick 9-A 병합 `ca0709b` / v0.2.7 code18
- 날짜: 2026-11-08
- 범위: 사진 분석 홈, pHash 분석 엔진, 별도 WorkManager/Room 캐시, 사진 진행·일시정지·재개·상태 UI
- 다음 단계(9-C): 유사 사진 그룹 결과 목록, 가로 비교, 다중 보관, 보호/휴지통 재검증 및 Android 승인

## 사용자 경험

1. 정리 탭의 '사진 비교' 섹션에 기존 '완전히 같은 파일 찾기'와 신규 '비슷한 사진 찾기'를 나란히 배치합니다. 기존 4개 메인 탭은 변경하지 않습니다.
2. 사진 분석 화면은 기존 브랜드(크림·민트·진녹색과 gp_cat_search)를 유지합니다. 분석 전/준비 중/진행 중/일시정지/완료/실패/권한 없음/파일 조회 실패를 구별합니다.
3. '사진 분석 시작'을 누르면 기기 내 사진을 작은 미리보기로 분석합니다. 진행 수는 성공+제외 건수로 표시하며, 분석이 완료되어도 파일을 자동 선택·삭제하지 않습니다.
4. 복귀, 일시정지, 재개는 독립된 사진 분석 세션만 바꿉니다. 기존 SHA-256 중복 분석은 별도 세션/워커로 유지됩니다.
5. 아직 결과 비교 화면이 없으므로 9-B에서는 '유사 사진 비교가 가능하다'는 메시지·무동작 버튼을 노출하지 않습니다. 완료 안내에 다음 단계 제공 예정임을 명시합니다.

## 분석 정책

- 입력: 현재 MediaStore가 접근을 허용한 사진 중 휴지통/0바이트를 제외한 파일. 사용자의 서버나 계정에 업로드하지 않습니다.
- 파일 읽기: Android ImageDecoder로 32×32 소프트웨어 비트맵을 추출합니다. ARGB → 명도 → 정규화 2D DCT → 저주파 8×8 계수의 중앙값을 이용해 64비트 pHash를 생성합니다.
- pHash는 시각적 후보 지표일 뿐 동일 파일이라는 증명이 아닙니다. 해시 거리와 묶음 기준은 9-C에서 실험적으로 검수합니다.
- 파일 읽기 전후에 fingerprint(MediaStore 크기/수정일/세대번호)·볼륨 버전을 확인합니다. 읽기 실패는 null 결과로 격리하고 성공으로 집계하지 않습니다.
- Room `photo_phash`, `photo_scan_session`를 v2→v3로 안전하게 추가하며 기존 `media_hash`, `scan_session`, `protected_media`, `protected_folder`를 변경/삭제하지 않습니다.
- 기존 pHash 캐시는 URI+fingerprint+볼륨버전으로 식별합니다. 미디어가 삭제·변경되거나 볼륨 버전이 변경되면 캐시가 무효화됩니다.
- WorkManager는 기존 `gallipick-duplicate-analysis`와 다른 고유 이름을 사용합니다. 취소된 세션에서 나중에 기록을 남기지 않도록 토큰 검증 후 저장합니다.
- 약 115초 단위로 WorkManager 작업을 분할하고, 중간 결과를 저장하며, 재개 시 이미 분석한 유효한 사진을 재사용합니다.
- 권한 거부/부분 권한/갤러리 갱신/사진 손상/일시정지 재개를 테스트합니다. 실행한 파일은 절대로 자동 휴지통 이동하지 않습니다.

## 검증

- JVM: 고정 썸네일 재현성, 전혀 다른 도형 구별, 16자리 해시와 거리 유효성, 컬러/알파의 정규화.
- Android Room: 추가 캐시의 볼륨버전 선택적 무효화, 기존 보호·SHA 캐시 보존, null 실패 캐시 처리.
- Android UI: 실행/일시정지/재개/완료/권한 거부 상태와 기존 중복 버튼 독립.
- Android 통합: 실제 테스트 미디어 삽입→미리보기 pHash→동일 이미지 해시 확인→기존 중복 캐시 불변.
- 5환경 실제 Activity 캡처: phone portrait/landscape/160% font, tablet portrait/landscape. 기존 15장/16장 캡처 기준을 변경하지 않고 9-B 분석 홈 1장을 별도 저장.
- 최종 게이트: Android verification, Android device tests, Adaptive UI native captures 완료 후에만 PR 병합.
- Google Play 배포, 버전 변경, 결과 비교 및 유사 사진 삭제는 범위 밖입니다.
