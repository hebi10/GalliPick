GalliPick 개인정보처리방침

시행일: 2026년 11월 20일
개발자: hebi
대상 앱: GalliPick (com.hebi.gallipick)

회원 탈퇴 및 클라우드 데이터 삭제 요청 안내

1. 처리 목적과 범위

GalliPick은 사용자가 접근을 허용한 기기의 사진과 동영상을 조회하고 검색, 정렬, 미리보기, 중복 검사, 휴지통 이동 및 복원 요청을 제공하는 앱입니다. 파일 검색·정리·중복 분석 등 기본 기능은 기기 안에서 처리합니다. 사용자가 개발 시험용 클라우드 백업을 선택해 활성화하면 선택한 사진·동영상 원본과 관련 파일 정보를 Firebase 인증을 거쳐 클라우드 서버에 전송하고, 본인 계정에서 다시 열람하거나 복원할 수 있습니다. 클라우드 백업은 기본적으로 활성화되지 않으며 이용자 동의와 계정 인증이 필요합니다.

2. 기기에서 접근·처리하는 정보

기능 제공을 위해 허용된 사진·동영상의 내용과 파일 이름, 폴더, 파일 크기, 날짜, 해상도, 영상 길이, 즐겨찾기·휴지통 상태 등의 정보를 처리합니다.

파일 전체 내용이 같은지 확인하기 위해 SHA-256 해시를 계산합니다. 비슷한 사진과 연속 촬영 후보를 찾기 위해 사진을 축소한 뒤 시각적 특징(pHash), 촬영 시각을 분석합니다. 또한 사진의 가장자리 변화로 선명도가 낮을 수 있는 사진을 추정합니다. 유사도와 선명도는 참고용이며 자동 삭제나 원본 판정에 사용하지 않습니다.

정확한 원본 바이트 비교를 위해 사진에 포함된 위치 메타데이터 접근 권한을 요청할 수 있습니다. 현재 GPS 위치를 조회하거나 이동 경로를 추적하지 않습니다.

3. 기기에 저장하는 정보

미디어 목록의 메타데이터, 중복 검사 SHA-256 해시와 진행 상태, 사진의 시각적 특징(pHash) 및 선명도 추정값, 분석 진행 상태, 보호한 파일·폴더, 검색 조건과 프리셋, 화면 테마 등의 설정을 앱의 로컬 저장 공간에 보관합니다.

사용자가 승인한 휴지통 이동·복원 결과 중 파일 상태가 실제로 확인된 작업은 별도의 정리 기록으로 보관합니다. 정리 기록에는 작업 유형, 시각, 요청·확인 건수, 확인된 파일 용량만 포함하며 파일 이름·파일 URI·사진 원본은 기록에 포함하지 않습니다. 클라우드 시험 기능에서는 Google 로그인으로 확인한 Firebase UID, 인증 상태, 저장공간 이용 상태, 원본 파일명·폴더·크기·파일 유형·촬영 시각·해상도·영상 길이·SHA-256 및 선택한 사진·영상 원본을 기능 제공에 필요한 범위에서 처리합니다. 클라우드 저장공간 시험 구매가 있는 경우 Google Play 구매 확인에 필요한 상품 및 구매 토큰이 처리될 수 있습니다.

4. 외부 앱에서 파일 열기

사용자가 외부 앱에서 원본 열기를 선택하면 Android를 통해 해당 파일의 읽기 권한을 전달할 수 있습니다. 이후 해당 외부 앱의 데이터 처리는 그 앱의 정책에 따릅니다. GalliPick의 기기 전용 정리 기능은 사용자가 승인하지 않은 원본을 외부 서버로 자동 업로드하지 않습니다. 클라우드 백업은 사용자가 선택한 기능·폴더·실행 조건에 따라 Firebase 서비스를 통해 원본을 전송할 수 있으며, 외부 앱 열기와는 별개의 동작입니다.

5. 선택형 클라우드 백업과 외부 처리

허용된 시험 계정이 클라우드를 사용하면 Google Firebase Authentication(로그인), Firestore(계정별 원본 및 저장공간 메타데이터), Google Cloud Storage(선택한 사진·영상 원본)를 사용합니다. 다운로드 및 앱 내 스트리밍을 위해 짧은 유효 기간의 인증된 접근 주소를 사용할 수 있습니다. 앱은 사용자가 기기 원본을 정리한 경우에도 별도로 보관 중인 클라우드 원본을 임의로 함께 삭제하지 않습니다.

계정 UID는 저장된 파일에 대한 권한을 구분하는 데 사용합니다. 원본 목록과 사진 썸네일은 현재 앱 사용 세션의 메모리에 일시적으로 보관할 수 있으며 로그인 계정이 바뀌면 이전 계정 목록과 썸네일 캐시를 사용하지 않습니다. 명시적인 기기 복원 없이 클라우드 원본을 Android 갤러리에 영구 저장하지 않습니다.

시크릿 클라우드 비밀번호는 앱 안의 보관함 접근을 추가로 보호합니다. 일반·시크릿 클라우드 원본은 Google Cloud Storage의 Google 관리 키로 암호화해 저장합니다. 시크릿 클라우드 비밀번호는 원본을 암호화하는 키로 사용되지 않습니다.

클라우드 시험 계정의 파일은 해당 원본을 보관해야 하는 동안 서버에 유지될 수 있으며 로그아웃이나 앱 삭제만으로 서버 저장 파일이 자동 삭제된다고 보장하지 않습니다. 클라우드 이용 중단, 계정 연관 데이터 확인 또는 서버 원본 삭제 요청은 아래 문의 주소로 접수할 수 있습니다. 처리 가능 범위와 신원·권한을 확인한 뒤 회신합니다.

6. 보관과 삭제

로컬 분석 정보와 설정은 사용 중 기기에 보관됩니다. 설정의 분석 캐시 비우기는 SHA-256·사진 pHash·선명도 분석 캐시와 관련 진행 상태를 초기화하며 보호 설정과 정리 기록은 유지합니다.

정리 기록 화면에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 이 작업은 기록만 삭제하며 미디어 파일, 보호 설정, Android 휴지통에는 영향을 주지 않습니다. 전체 앱 데이터는 Android의 앱 데이터 삭제 또는 앱 제거 기능으로 정리할 수 있습니다. 앱 데이터 관리와 원본 미디어의 휴지통 관리는 별개입니다.

미디어의 휴지통 이동과 복원은 사용자의 확인 및 Android 승인 절차를 거칩니다. 휴지통 보관 기간과 실제 제거는 Android와 기기 정책에 따릅니다.

6-1. 구독 취소·클라우드 데이터 삭제·회원 탈퇴

구독 취소: Google Play에서 GalliPick 구독에 사용한 Google 계정으로 정기 결제 관리를 열고 해당 구독을 선택하여 취소할 수 있습니다. 구독을 취소하면 일반적으로 이미 결제한 이용 기간의 종료 시점까지 혜택이 유지됩니다. 로그아웃, 앱 삭제, 클라우드 데이터 삭제 또는 회원 탈퇴 요청만으로 Google Play의 자동 갱신이 취소되지는 않습니다. 구독 취소 여부는 Google Play에서 직접 확인해 주세요.

클라우드 데이터만 삭제: GalliPick 계정을 유지하면서 저장한 사진·동영상 원본(시크릿 클라우드 포함)과 관련 서버 메타데이터의 삭제를 요청할 수 있습니다. 요청은 클라우드 데이터 삭제 요청 이메일로 접수합니다. 이 요청은 Google Play 구독 취소나 기기 원본 삭제를 의미하지 않습니다.

회원 탈퇴 및 연관 데이터 삭제: GalliPick 로그인 계정과 관련 클라우드 데이터를 함께 삭제하려면 회원 탈퇴 요청 이메일을 보내 주세요. 이는 기기의 Google 계정 자체를 삭제하는 기능이 아닙니다. 클라우드를 더 이상 사용하지 않더라도 유료 구독 중이라면 Google Play에서 구독 취소를 별도로 진행해 주세요. 구독 중에도 탈퇴 요청을 접수할 수 있습니다.

요청 시 이용 중인 Google 로그인 이메일, 요청 종류(클라우드 데이터만 삭제 또는 계정 전체 삭제), 연락 가능한 회신 주소를 알려 주세요. 사진·동영상 원본, 비밀번호, Google Play 구매 토큰은 이메일에 첨부하지 마세요. 계정 소유권을 안전하게 확인한 뒤 처리 범위와 결과를 회신합니다. 이메일 발송이나 요청 접수만으로 삭제가 완료된 것은 아니며, 서버 원본·관련 메타데이터가 실제 삭제됐는지 확인한 후 완료를 안내합니다.

법령 준수, 결제 분쟁 처리 또는 부정 사용 방지 등을 위해 일부 기록의 보존이 필요한 경우에는 해당 항목, 근거 및 보존 기간을 별도로 안내합니다. 구독 종료 또는 로그아웃 시점에 클라우드 원본이 자동 삭제된다고 안내하지 않습니다. 기기 갤러리에 남아 있는 원본은 위 서버 데이터 삭제 요청 대상이 아닙니다.

7. 접근 제어와 백업

앱은 Android 권한과 앱별 저장 공간을 사용합니다. 사용자는 Android 설정에서 사진·동영상 접근 권한을 변경하거나 철회할 수 있습니다. 선택형 클라우드 시험 기능은 별도의 Google 계정 인증과 이용권·서버 접근 검사를 필요로 합니다. Android 자동 백업과 기기 간 데이터 이전에서는 앱 데이터를 제외하도록 설정되어 있으며, 이는 선택형 클라우드 원본 보관 기능과 다릅니다.

8. 광고 제공 및 선택

광고 기능이 활성화된 버전은 Google AdMob을 통해 홈 화면에 배너 광고를 표시할 수 있습니다. 서버에서 확인한 로그인 계정의 클라우드 구독이 유효한 동안 홈 배너 광고가 표시되지 않습니다. 광고에는 Google의 광고 기술과 기기 광고 식별자·광고 상호작용 정보 등이 사용될 수 있으며, 실제 처리 범위는 지역과 광고 설정·사용자의 동의 선택에 따라 달라집니다. 자세한 내용은 Google 개인정보처리방침과 앱의 광고 동의 화면을 확인해 주세요.

사용자에게 광고 개인정보 선택 변경이 필요한 경우 앱 설정에서 해당 화면을 다시 열 수 있습니다. 사용자가 동의가 필요한 지역에서 동의를 제공하지 않은 경우, 앱은 동의 관리 도구의 광고 요청 허용 여부를 따릅니다. 광고를 포함한 버전을 출시할 때는 Google Play의 광고·광고 ID·데이터 보안 신고가 실제 배포 SDK 구성과 일치하도록 갱신합니다.
