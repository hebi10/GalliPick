GalliPick 개인정보처리방침

시행일: 2026년 11월 8일
개발자: hebi
대상 앱: GalliPick (com.hebi.gallipick)

1. 처리 목적과 범위

GalliPick은 사용자가 접근을 허용한 기기의 사진과 동영상을 조회하고 검색, 정렬, 미리보기, 중복 검사, 휴지통 이동 및 복원 요청을 제공하는 앱입니다. 이러한 기능은 기기 안에서 처리하며 사진·동영상이나 분석 결과를 개발자 서버로 자동 전송하는 기능을 제공하지 않습니다.

2. 기기에서 접근·처리하는 정보

기능 제공을 위해 허용된 사진·동영상의 내용과 파일 이름, 폴더, 파일 크기, 날짜, 해상도, 영상 길이, 즐겨찾기·휴지통 상태 등의 정보를 처리합니다.

파일 전체 내용이 같은지 확인하기 위해 SHA-256 해시를 계산합니다. 비슷한 사진과 연속 촬영 후보를 찾기 위해 사진을 축소한 뒤 시각적 특징(pHash), 촬영 시각을 분석합니다. 또한 사진의 가장자리 변화로 선명도가 낮을 수 있는 사진을 추정합니다. 유사도와 선명도는 참고용이며 자동 삭제나 원본 판정에 사용하지 않습니다.

정확한 원본 바이트 비교를 위해 사진에 포함된 위치 메타데이터 접근 권한을 요청할 수 있습니다. 현재 GPS 위치를 조회하거나 이동 경로를 추적하지 않습니다.

3. 기기에 저장하는 정보

미디어 목록의 메타데이터, 중복 검사 SHA-256 해시와 진행 상태, 사진의 시각적 특징(pHash) 및 선명도 추정값, 분석 진행 상태, 보호한 파일·폴더, 검색 조건과 프리셋, 화면 테마 등의 설정을 앱의 로컬 저장 공간에 보관합니다.

사용자가 승인한 휴지통 이동·복원 결과 중 파일 상태가 실제로 확인된 작업은 별도의 정리 기록으로 보관합니다. 정리 기록에는 작업 유형, 시각, 요청·확인 건수, 확인된 파일 용량만 포함하며 파일 이름·파일 URI·사진 원본은 기록에 포함하지 않습니다. 계정 가입 기능은 없으며 광고·분석·외부 오류 수집 SDK를 사용하지 않습니다.

4. 외부 앱에서 파일 열기

사용자가 외부 앱에서 원본 열기를 선택하면 Android를 통해 해당 파일의 읽기 권한을 전달할 수 있습니다. 이후 해당 외부 앱의 데이터 처리는 그 앱의 정책에 따릅니다. GalliPick이 사진·동영상을 자동으로 외부 앱이나 서버에 전송하지는 않습니다.

5. 보관과 삭제

로컬 분석 정보와 설정은 사용 중 기기에 보관됩니다. 설정의 분석 캐시 비우기는 SHA-256·사진 pHash·선명도 분석 캐시와 관련 진행 상태를 초기화하며 보호 설정과 정리 기록은 유지합니다.

정리 기록 화면에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 이 작업은 기록만 삭제하며 미디어 파일, 보호 설정, Android 휴지통에는 영향을 주지 않습니다. 전체 앱 데이터는 Android의 앱 데이터 삭제 또는 앱 제거 기능으로 정리할 수 있습니다. 앱 데이터 관리와 원본 미디어의 휴지통 관리는 별개입니다.

미디어의 휴지통 이동과 복원은 사용자의 확인 및 Android 승인 절차를 거칩니다. 휴지통 보관 기간과 실제 제거는 Android와 기기 정책에 따릅니다.

6. 접근 제어와 백업

앱은 Android 권한과 앱별 저장 공간을 사용합니다. 사용자는 Android 설정에서 사진·동영상 접근 권한을 변경하거나 철회할 수 있습니다. 앱에는 자체 클라우드 동기화 기능이 없으며 Android 자동 백업과 기기 간 데이터 이전에서 앱 데이터를 제외하도록 설정되어 있습니다.
