GalliPick 개인정보처리방침

시행일: 2026년 11월 16일
개발자: hebi
대상 앱: GalliPick (com.hebi.gallipick)

1. 처리 목적과 범위

GalliPick은 사용자가 접근을 허용한 기기의 사진과 동영상을 조회하고 검색, 정렬, 미리보기, 중복 검사, 휴지통 이동 및 복원 요청을 제공하는 앱입니다. 파일 정리·중복 분석 등 기본 기능은 기기 안에서 처리합니다. 사용자가 별도로 클라우드 백업에 동의하면 선택한 사진·동영상 원본과 촬영 정보가 Google Firebase 서비스를 통해 계정별로 보관될 수 있습니다. 클라우드 백업은 자동으로 활성화되지 않으며, 사용자가 폴더와 실행 조건을 선택합니다.

2. 기기에서 접근·처리하는 정보

기능 제공을 위해 허용된 사진·동영상의 내용과 파일 이름, 폴더, 파일 크기, 날짜, 해상도, 영상 길이, 즐겨찾기·휴지통 상태 등의 정보를 처리합니다.

파일 전체 내용이 같은지 확인하기 위해 SHA-256 해시를 계산합니다. 비슷한 사진과 연속 촬영 후보를 찾기 위해 사진을 축소한 뒤 시각적 특징(pHash), 촬영 시각을 분석합니다. 또한 사진의 가장자리 변화로 선명도가 낮을 수 있는 사진을 추정합니다. 유사도와 선명도는 참고용이며 자동 삭제나 원본 판정에 사용하지 않습니다.

정확한 원본 바이트 비교를 위해 사진에 포함된 위치 메타데이터 접근 권한을 요청할 수 있습니다. 현재 GPS 위치를 조회하거나 이동 경로를 추적하지 않습니다.

3. 기기에 저장하는 정보

미디어 목록의 메타데이터, 중복 검사 SHA-256 해시와 진행 상태, 사진의 시각적 특징(pHash) 및 선명도 추정값, 분석 진행 상태, 보호한 파일·폴더, 검색 조건과 프리셋, 화면 테마 등의 설정을 앱의 로컬 저장 공간에 보관합니다.

사용자가 승인한 휴지통 이동·복원 결과 중 파일 상태가 실제로 확인된 작업은 별도의 정리 기록으로 보관합니다. 정리 기록에는 작업 유형, 시각, 요청·확인 건수, 확인된 파일 용량만 포함하며 파일 이름·파일 URI·사진 원본은 기록에 포함하지 않습니다. 클라우드 서비스를 선택한 경우 Google 계정 인증 정보와 백업 파일 메타데이터·저장공간 이용 상태를 처리할 수 있습니다. 광고가 포함된 앱 버전에서는 Google AdMob 광고 SDK와 동의 관리 도구(UMP)가 사용될 수 있으며, 해당 버전에서 광고 제공을 허용한 경우 광고 요청에 필요한 기기 정보·광고 식별자 등이 처리될 수 있습니다.

4. 외부 앱에서 파일 열기

사용자가 외부 앱에서 원본 열기를 선택하면 Android를 통해 해당 파일의 읽기 권한을 전달할 수 있습니다. 이후 해당 외부 앱의 데이터 처리는 그 앱의 정책에 따릅니다. 기본 파일 정리 기능이 사진·동영상을 개발자 서버에 임의로 전송하지는 않습니다. 단, 사용자가 별도로 선택한 클라우드 원본 백업과 외부 앱에서 열기는 각각 해당 요청에 따라 처리됩니다.

5. 보관과 삭제

로컬 분석 정보와 설정은 사용 중 기기에 보관됩니다. 설정의 분석 캐시 비우기는 SHA-256·사진 pHash·선명도 분석 캐시와 관련 진행 상태를 초기화하며 보호 설정과 정리 기록은 유지합니다.

정리 기록 화면에서 개별 기록 또는 전체 기록을 삭제할 수 있습니다. 이 작업은 기록만 삭제하며 미디어 파일, 보호 설정, Android 휴지통에는 영향을 주지 않습니다. 전체 앱 데이터는 Android의 앱 데이터 삭제 또는 앱 제거 기능으로 정리할 수 있습니다. 앱 데이터 관리와 원본 미디어의 휴지통 관리는 별개입니다.

미디어의 휴지통 이동과 복원은 사용자의 확인 및 Android 승인 절차를 거칩니다. 휴지통 보관 기간과 실제 제거는 Android와 기기 정책에 따릅니다.

6. 접근 제어와 백업

앱은 Android 권한과 앱별 저장 공간을 사용합니다. 사용자는 Android 설정에서 사진·동영상 접근 권한을 변경하거나 철회할 수 있습니다. 선택형 클라우드 백업 기능을 이용하는 경우 Google 계정과 서버의 원본 저장 및 복원 권한 정책이 적용됩니다. 일반 Android 자동 백업과 기기 간 데이터 이전에서는 앱 데이터를 제외하도록 설정되어 있습니다.

7. 광고 제공 및 선택

광고 기능이 활성화된 버전은 Google AdMob을 통해 앱 화면 일부에 배너 광고를 표시할 수 있습니다. 광고에는 Google의 광고 기술과 기기 광고 식별자·광고 상호작용 정보 등이 사용될 수 있으며, 실제 처리 범위는 지역과 광고 설정·사용자의 동의 선택에 따라 달라집니다. 자세한 내용은 Google 개인정보처리방침과 앱의 광고 동의 화면을 확인해 주세요.

사용자에게 광고 개인정보 선택 변경이 필요한 경우 앱 설정에서 해당 화면을 다시 열 수 있습니다. 사용자가 동의가 필요한 지역에서 동의를 제공하지 않은 경우, 앱은 동의 관리 도구의 광고 요청 허용 여부를 따릅니다. 광고를 포함한 버전을 출시할 때는 Google Play의 광고·광고 ID·데이터 보안 신고가 실제 배포 SDK 구성과 일치하도록 갱신합니다.
