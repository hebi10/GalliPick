# GalliPick 7-F — 설정·정리 결과·예외 화면 정밀 보정

## 기준
- 디자인 원본: Google Drive 원본 9화면 시안 및 'GalliPick 7단계 원본시안-실제캡처 정밀비교 기획안'
- 비교 기준: 비공개 테스트 v0.2.4/code15, 7-E 실제 Android 캡처 5개 프로필
- 작업 범위: S-01~04, R-01~04. Android 권한, 해시/중복 판정, 파일 이동·복원 로직과 Play 릴리스 동작 불변

## 확인한 차이와 보정
- S-01 기존 휴대폰 세로 밝은/어두운 테마 캡처의 설정은 넓은 카드·큰 테마 라디오가 차지하는 공간이 컸음. 원본의 압축형 목록을 참고해 정보 블록의 시각 밀도 개선
- S-02 설정 공통 카드: 기존 브랜드 표면·테두리·타이포 규칙을 재사용해 아이콘 40→32dp, 섹션 제목 titleMedium→titleSmall, 카드 안쪽 패딩 14→12dp(가로)/10dp(세로), 섹션 간 간격 14~18→10~12dp
- S-03 화면 테마: 기기 설정 따르기/라이트/다크의 3가지 모드 및 선택 지속성 유지하면서 중복 상태 문구를 줄이고 48dp 이상 선택 영역 보존. 권한·휴지통·보호 폴더·캐시·개인정보 원래 동작 보존
- S-04 보호 폴더 그림 64→44dp, 큰 글씨·짧은 화면에서도 폴더 관리/복원/권한 버튼과 설명이 모두 접근 가능한지 기기 테스트
- R-01 성공 결과: 작은 캐릭터와 수치 배치에서 성공 시 큰(116dp) 캐릭터·가운데 제목·실제 처리 확인 건수 강조 구조로 보정
- R-02 전체 화면 라우트 전환 대신 기존 Result Dialog 유지. 전체 화면으로 바꾸면 뒤로가기/복원/정리 경로 변경이 필요한데 현재 원본과 기능을 보호해야 하므로 모달의 높이를 줄이고 중심 계층을 개선
- R-03 PARTIAL/CANCELED/FAILED/UNKNOWN은 성공 캐릭터·확인 건수 강조를 사용하지 않으며 실제 완료 여부를 명확히 구분. 복원 요청 시 요청 용량을 확보 공간이라고 오해하지 않도록 별도 안내
- R-04 홈/다음 정리 후보/휴지통 확인 목적지, Android MediaStore 실제 결과 재조회, 작업 상태 집계, 확인 전 자동 성공 처리 없음 유지

## 검증 기준
1. Android verification(Lint, JVM tests, 컴파일)
2. Android device tests: ThemeSettingsTest에서 모드 즉시 적용/재시작 보존, CleanupResultDialogTest에서 다섯 상태의 개별 메시지·건수·스토리지 안내/후속 버튼 확인
3. Native capture 5 profiles(휴대폰 세로·가로·160% 글꼴, 태블릿 세로·가로)에서 14개 실제 앱 화면 + 16개 모달/상세 화면을 캡처. 추가된 4개 결과 캡처는 partial/canceled/failed/unknown
4. 실제 Light/Dark 설정과 성공/오류 결과의 before-after 사진 비교. 상태바·내비게이션 겹침·잘림·컴포넌트 접근성 검사
5. 모든 검증 성공 및 실제 캡처 육안 검수 후 main 병합

## 남은 단계
7-G 전체 9화면 전수 비교 및 잔여 보정. Google Play v0.2.4(code15) 비공개 테스트는 변경하지 않음.
