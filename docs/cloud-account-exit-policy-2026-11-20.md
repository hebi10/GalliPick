# GP-CLOUD-EXIT — 로그인 진입·구독 취소·계정 및 클라우드 데이터 삭제 지침

- 기준일: 2026-11-20
- 상태: 클라우드 화면 진입 수정 및 삭제 요청 안내 구현. 서버 원본·계정 자동 삭제 기능은 별도 개발 및 검증 대상.
- 근거: `CloudAccountSettings.kt`, `CloudScreenNavigationTest.kt`, `firebase/functions/cloud-billing.js`, `firebase/functions/backup.js`, `firebase/functions/secret-cloud.js`, `docs/privacy.html`.

## 1. 로그인·요금제 화면

- **클라우드 탭**에서 Google 로그인에 성공하면 기본 화면인 **클라우드**에 머문다. 요금제·결제 화면으로 자동 이동하지 않는다.
- 구독을 원하는 사용자가 클라우드 화면의 **요금제·결제** 메뉴를 직접 누를 때만 해당 화면을 표시한다.
- 홈의 **광고 제거**처럼 결제를 명시적으로 선택하고 시작한 별도 진입점은 기존 의도에 따라 로그인 후 해당 결제 화면을 표시할 수 있다.
- 새 계정의 구매 가능 여부와 로그인 후 화면 이동은 별개의 정책이다. 운영 Functions의 `license-test` 허용 목록에 없는 계정은 `getCloudPlan` 호출이 제한되므로 자동 화면 이동을 제거해도 결제 자격은 바뀌지 않는다.
- 현재 운영 결제의 `live` 전환, Play 상품 활성화, 금액 변경, 실제 유료 결제 개방은 이 작업의 범위에 포함하지 않는다. 특히 운영 서버 설정 변경은 구독 실결제와 백업 비용에 영향을 주므로 별도 승인·검증 후 시행한다.

## 2. 구독 취소

**사용자 경로**: 클라우드 → 요금제·결제 → Google Play에서 구독 관리 → 해당 구독 선택 → 구독 취소. 계정 화면의 'Google Play 구독 취소·관리'에서도 구독 목록으로 이동할 수 있다.

- 취소는 **Google Play**에서 해당 구독을 구매한 Google 계정으로 진행한다. 앱 내 안내 버튼을 누르는 것만으로 취소되지 않는다.
- 구독 해지 후 이미 결제한 기간은 Play에서 확인되는 만료일까지 일반적으로 유지한다. 실제 서비스 혜택은 서버에서 검증한 사용권과 만료일을 따른다.
- 로그아웃, 앱 삭제, 클라우드 파일 삭제, GalliPick 회원 탈퇴 요청은 **Google Play 구독 취소가 아니다**. 특히 계정 삭제 요청 화면에서 자동 갱신을 먼저 확인할 수 있도록 안내한다.
- 구독 취소 자체는 환불을 보장하지 않으며, 기기 원본·클라우드 원본을 삭제하지 않는다.
- 공식 Google Play 관리: https://play.google.com/store/account/subscriptions

## 3. 클라우드 데이터 삭제(계정 유지)

**사용자 경로(현재 지원)**: 클라우드 → 계정·데이터 관리 → 클라우드 데이터 삭제 요청 → 이메일 작성·전송 → 본인 확인 및 처리 결과 안내.

- 삭제 범위: 선택한 계정의 일반 클라우드 및 시크릿 클라우드 **원본 객체, 메타데이터, 중단된 업로드 예약, 관련 캐시**. 향후 단일 파일 삭제를 제공한다면 전체 삭제와 별도 API·화면으로 구현한다.
- 유지 항목: GalliPick 앱 계정과 유효한 구독은 유지한다. 기기 갤러리 원본·Android 휴지통·다른 사용자의 데이터는 변경하지 않는다.
- 삭제 전: Google 로그인 소유권 확인, 저장 중인 데이터 규모·범위 확인, 업로드/복원 중인 작업과 자동 백업 중지, 영구 삭제 확인 단계를 거친다. 재업로드 경합을 차단해야 한다.
- 삭제 실행(향후): 서버 측 UID 소유권 검증 → 삭제 상태 잠금 → 일반/시크릿 및 개발/라이선스/운영 저장 영역별 객체 세대 검증 삭제 → Firestore 색인·예약·비밀보관함 상태 정리 → 실제 객체와 메타데이터의 삭제 완료 확인 → 상태 갱신·결과 통지.
- 실패한 항목은 재시도 가능한 삭제 작업으로 남기고, 미완료 상태를 '삭제 완료'라고 표시하지 않는다. 클라우드 원본을 지우는 행위가 기기 원본 삭제로 전파되지 않도록 분리한다.

## 4. 회원 탈퇴(계정·연관 데이터 삭제)

**사용자 경로(현재 지원)**: 클라우드 → 계정·데이터 관리 → 회원 탈퇴 요청 → 이메일 작성·전송 → 본인 확인 → 탈퇴 및 연관 데이터 처리 결과 안내.

- 단순 로그아웃은 탈퇴가 아니다. GalliPick의 Firebase 로그인 계정과 연결 데이터 삭제를 요청하며 기기 Google 계정 자체는 삭제하지 않는다.
- 탈퇴 요청은 구독 활성 중에도 받을 수 있지만 Google Play 자동 갱신은 별도 취소해야 한다는 점을 사전 고지한다. 취소하지 않았다는 이유만으로 삭제 요청 자체를 숨기지 않는다.
- 처리 대상: Authentication 사용자, 계정별 구독·백업 메타데이터, 일반/시크릿 클라우드 객체, 비밀보관함 인증 기록/세션, 미완료 전송·업로드 예약, 계정별 임시 데이터. 운영·라이선스 시험·개발의 격리된 저장 영역을 정확히 구별한다.
- 처리 순서(향후): 재인증·서버 확인 → 새로운 쓰기 차단 및 삭제 작업 ID 생성 → 원본·메타데이터 삭제 및 결과 확인 → Authentication 사용자 삭제. 중간 실패 시 자격 증명이 먼저 사라져 복구·재요청이 막히지 않도록 순서를 보존한다.
- 구매 토큰은 링크 또는 로그에 노출하지 않는다. 법령·결제 분쟁·부정 이용 방지 등 정당한 보존 의무가 있는 데이터는 항목·법적 근거·보유 기간을 확정하여 정책에 반영한다. 보관 기간을 임의로 약속하지 않는다.

## 5. 현재 제공하는 삭제 요청 경로

- 앱 내 '클라우드 데이터 삭제 요청'과 '회원 탈퇴 요청' 버튼은 각각 이메일 앱을 연다. 이용자가 **메일을 실제 전송해야** 요청이 접수된다.
- 현재 개인정보처리방침의 `#account-deletion`에 앱 밖에서도 접근 가능한 요청 경로와 문의 주소가 있다. 공식 링크: https://hebi10.github.io/GalliPick/privacy.html#account-deletion
- 개인정보처리방침 안내는 기기 원본과 서버 데이터 삭제 범위를 명확히 구분한다. 신원 확인을 위해 사용자에게 사진·영상, 비밀번호, 구매 토큰 제출을 요구하지 않는다.
- 이메일 앱 미설치 등으로 호출이 실패하면 문의 주소와 개인정보처리방침을 안내한다.
- **현 상태**: 요청 접수 안내 및 Google Play 관리 링크는 코드로 제공. 자동 대량 삭제 API, 앱 내 즉시 탈퇴, 삭제 진행·완료 확인은 아직 구현/검증되지 않았으며 배포 시 완료로 선언하지 않는다.

## 7. QA 및 배포 제약

- PR 필수 테스트 성공을 확인하고 병합한다. 사용자 승인 없는 운영 Firebase 설정 변경, Play 자동 상품 개방, Firebase 서버 배포, Google Play 업로드를 수행하지 않는다.
- 전체 Android 계측은 기능 배치 확정 후 최신 `main` SHA에서 한 차례 수행한다. 이 작업의 버튼은 삭제를 실행하지 않으므로 서버 삭제 안전 검증을 대체하지 않는다.
- 공개/내부 계정 삭제 실기기 검증 전에 '자동 탈퇴 완성'이나 '데이터 완전 삭제 보장'으로 표시하지 않는다.
