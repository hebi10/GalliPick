# GalliPick 8-C — 중복 파일 묶음 가로 스크롤 리디자인

2026-11-07, 8-A·8-B를 병합한 `main` 기준.

## 변경 범위
- 세로로 길게 나열하던 파일별 행을 '중복 묶음 1개 카드 + 내부 LazyRow'로 변경합니다.
- 묶음 내부 첫 번째는 항상 `DuplicateRoles.keeper`가 결정한 남길 파일이며, 나머지 유지·보호/즐겨찾기 파일과 정리 후보를 순서대로 표시합니다. 각 항목의 key는 실제 `MediaItem.uri`.
- 일반 휴대폰 카드 폭 132dp/미리보기 높이 116dp, 좁고 짧은 가로 화면 컴팩트 카드 폭 106dp/높이 68dp. 파일명 1줄 말줄임, 용량/동영상 시간·현재 역할 표시.
- 3개 이상 사본은 좌우 스크롤로 접근하며 2개도 같은 행에서 나란히 보이도록 구성합니다.
- 이미지 또는 파일명 탭은 기존 비교 화면을 열고, 선택 체크박스는 정리 가능한 사본에만 표시합니다. 보존 파일/보호/즐겨찾기 대상은 클릭 불가능한 남김 표시로 구분합니다.
- 묶음별 후보 선택, 전체 후보 선택, 500개 한도, 변경 중 파일 정체성 재확인, Android 시스템 휴지통 승인 경로는 그대로 유지합니다.
- 남길 파일을 바꾸는 '남기기' 조작은 기존 `AppViewModel.chooseDuplicateKeeper`를 재사용하므로 해당 묶음에서만 정리 선택 해제.
- 중복 파일을 선택했다고 실제 휴지통 요청을 호출하지 않으며, 최종 이동은 기존 바닥 '선택한 N개 휴지통으로 이동' 경로로만 진행합니다.
