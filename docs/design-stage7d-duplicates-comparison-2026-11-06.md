# GalliPick 7-D — 중복 결과·A/B 비교 정밀 보정

기준: Google Drive 원본 9화면 비교 기획안, 7-A의 실제 MediaStore 30개(중복 묶음 3개 이상), 7-B 최신 실기기 에뮬레이터 캡처.

## 작업 범위
- D-01~02: 중복 묶음이 3개 이상인 휴대폰 일반 글꼴 화면에서 미디어 행을 압축 레이아웃으로 표시하여 목록의 가시 밀도를 높입니다. 큰 글씨 160%는 기존 줄바꿈 중심 레이아웃으로 유지합니다.
- D-02: 중복 묶음당 미디어가 3개 이상이면 그룹 헤더 썸네일을 최대 3개가 겹치는 미리보기로 표시하고, 해당 영역을 누르면 기존 비교 화면으로 이동합니다. 첫 장은 남길 기준 파일, 나머지는 동일 묶음의 사본입니다.
- C-01: 휴대폰 세로 등 비교 탭을 사용하는 화면에서 높이 600dp 이상의 경우 A/B 역할명 아래 각각의 실제 파일 이름을 보여줍니다. 화면이 짧으면 기존 한 줄 역할 탭을 유지해 버튼 접근성을 확보합니다.
- C-02~03: 넓은 화면의 기존 좌우 동시 비교, 이미지 미리보기, 파일명/용량/경로/남길 파일 변경 동작, 비디오 재생 생명주기를 그대로 유지합니다.
- D-03~04: 전체/그룹별 후보 선택·보호 제외·남길 사본 정책 변경 없음. 화면에 표시되는 미디어 사진은 7-A MediaStore 검증 자료 그대로입니다.

## 검증
- Android verification (컴파일, 단위 테스트, Lint)
- Android device tests에서 중복 묶음 3개 이상의 썸네일·비교 연결과 휴대폰 400dp×800dp에서 두 파일명 A/B 표기 검증
- Adaptive UI verification and native captures(휴대폰 세로/가로/160%·태블릿 세로/가로) 결과 검수
- SHA-256 중복 판정, 보호/즐겨찾기, 남길 파일, Android 휴지통 승인 및 기존 안전 회귀 테스트 통과 필요
- 위 세 검증과 실제 캡처 비교가 성공한 경우에만 main 병합

## 제외
- 유사 이미지 탐지, 자동 정리, 영구 삭제, 앱 버전/서명/Play 트랙 변경 없음
- 영상 6개가 동일 원본 복제된 7-A fixture라는 한계를 그대로 기록. 여러 코덱/길이 검증으로 해석하지 않음.
