## 앱 이름

GalliPick

## 간단한 설명

사진·동영상을 용량과 길이로 찾고, 같은 사본을 비교해 휴지통으로 정리하세요.

## 자세한 설명

GalliPick은 기기 안의 사진과 동영상을 원하는 조건으로 찾고, 내용이 완전히 같은 사본을 비교해 정리하는 미디어 관리 앱입니다.

사진과 동영상 찾기
• 영상 길이, 파일 용량, 날짜, 이름, 화소 수로 정렬합니다.
• 폴더, 파일 형식, 날짜 범위, 용량, 영상 길이 등 여러 조건을 조합합니다.
• 자주 사용하는 검색 조건을 저장해 다시 적용합니다.

완전히 같은 사본 비교
• 파일 전체 내용을 확인해 완전히 같은 사본을 묶습니다.
• 남길 파일, 정리 후보, 선택한 이동 대상을 구분해 보여 줍니다.
• 파일 이름과 폴더, 용량, 영상 길이를 확인하고 사진과 동영상을 미리 봅니다.
• 가로 썸네일 목록에서 비교할 파일을 선택하고 상세 정보를 확인합니다.

비슷한 사진·연속 촬영 검토
• 기기 안에서 사진의 시각적 특징을 분석해 비슷해 보이는 사진 후보를 묶습니다.
• 촬영 시각이 가까운 연속 촬영 사진과 선명도가 낮을 수 있는 사진을 검토할 수 있습니다.
• 사진 유사도와 선명도는 참고용입니다. 가장 좋은 사진이나 원본을 자동으로 판정하지 않습니다.

확인 후 휴지통 이동
• 남길 파일을 직접 지정하고 파일과 폴더를 보호할 수 있습니다.
• 보호 파일과 즐겨찾기는 중복 정리 후보에서 제외합니다.
• 선택한 파일 수와 용량, 남길 사본을 확인한 뒤 Android 승인창에서 휴지통 이동을 결정합니다.
• 휴지통에 남아 있는 파일의 복원을 요청할 수 있습니다.
• 실제 상태를 확인한 휴지통 이동·복원 건수와 용량을 기기 내 정리 기록에서 확인하고, 기록만 개별·전체 삭제할 수 있습니다.

기기 안에서 처리
• 미디어 목록 조회와 중복 분석을 기기에서 처리합니다.
• 앱 자체의 서버 업로드, 계정 가입, 광고·분석 SDK를 사용하지 않습니다.
• 시스템 설정 따르기, 라이트 모드, 다크 모드를 지원합니다.

사용 안내
• Android 11 이상에서 사용할 수 있습니다.
• 사진과 동영상 접근을 허용한 범위에서 목록과 검사 결과를 표시합니다.
• 원본 사진의 정확한 중복 검사를 위해 사진에 포함된 위치 메타데이터 접근을 요청할 수 있습니다. 현재 GPS 위치를 추적하지 않습니다.
• 완전 중복(SHA-256)과 유사 사진 분석은 별도 기능입니다. 유사 동영상 탐지나 화질·원본 확정 판정은 제공하지 않습니다.
• 휴지통 이동만으로 저장 공간이 즉시 늘어나지는 않을 수 있습니다. 휴지통 보관 기간과 실제 제거는 Android와 기기 정책에 따릅니다.
