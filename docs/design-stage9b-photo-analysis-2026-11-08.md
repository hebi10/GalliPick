# GalliPick 9-B: 기기 내 사진 특징 분석

기준: v0.2.7, 9-A main 병합 ca0709b1080078a9b72382a54a76d2535452283b

## 범위
- 정리 > 비슷한 사진 찾기 > 사진 분석 홈 진입.
- 첫 화면의 '유사 사진' 분석 시작, 작업 중 진행률/제외 건수/일시정지/재개, 완료/오류/권한 제한 안내.
- 사진을 32×32픽셀로 디코딩한 명도값의 저주파 DCT 계수로 지각 해시(pHash)를 계산.
- 로컬 Room `photo_perceptual_hash`, `photo_analysis_session` 신규 테이블. 2→3 명시적 마이그레이션, 기존 미디어·완전 중복 해시·보호·즐겨찾기 유지.
- WorkManager 고유 작업명 `gallipick-photo-perceptual-analysis`으로 SHA-256 검사와 독립 실행, 완료한 파일별 캐시, 작업 시간 예산에 따른 이어서 검사, 취소 및 일시정지.
- 파일 URI·fingerprint·볼륨 버전으로 검사 전후 변경 확인. 권한·미디어 변경 시 캐시 재사용 제한. 파일 분석 실패는 제외 처리하고 수동 재분석에서 재시도.
- 분석 자체에는 삭제, 자동 파일 선택, 네트워크 API, 모델 다운로드가 없음.

## 9-B에서 의도적으로 제외
- 유사사진 묶음 결과 목록/썸네일/비교 및 휴지통 연동은 9-C.
- 연속 촬영/선명도 평가는 9-D, 9-E.
- 정리 이력은 9-F.
- 9-C가 구현되기 전에 분석 성공을 '유사 사진 N묶음'이나 'N GB 확보'로 표현하지 않음.

## 검증
- 단위: DCT 동일/명도 변화/해밍 거리/유효성, Room 캐시 별도 보관 및 볼륨 버전 무효화.
- Android: 접근 없음/일부 접근/진행/일시정지/완료 상태 UI. 기존 SHA-256 및 중복 비교/휴지통 기능의 전체 회귀.
- 5가지 실기기 유사 에뮬레이터 프로필 캡처는 9-G에 통합. 이번 단계에서는 Android verification 및 Android device tests를 병합 게이트로 사용.
- 테스트 실패나 권한/사진 내용 변경 시 성공으로 오인하지 않음.
- Google Play 비공개·내부·프로덕션 배포는 별도 사용자 요청 전까지 실행하지 않음.
