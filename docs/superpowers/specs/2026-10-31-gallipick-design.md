# GalliPick 설계

## 목적
기기 내부 사진·동영상을 복합 조건으로 찾고 동일 파일을 검증한 뒤 안전하게 정리하는 Android 앱입니다. 사용자 제공 기획안과 저장소 구현 요청을 실행 기준으로 삼습니다.

## 구현 선택
- Kotlin + Jetpack Compose, minSdk 30 / targetSdk 36. Android 11부터 시스템 휴지통을 일관되게 사용합니다.
- MediaStore 조회 + Room 캐시를 사용합니다. 파일을 임의 경로로 이동하거나 영구 삭제하지 않습니다.
- 메타데이터로 후보를 좁힌 뒤 전체 바이트 SHA-256을 비교합니다. 유사 사진·영상은 별도 후속 단계입니다.
- 대안인 웹 갤러리는 로컬 미디어 권한과 삭제 승인의 제약이 커 제외했습니다. 초기 AI 모델 도입은 정렬·완전 중복 검사에 불필요해 제외했습니다.
- 검사는 WorkManager의 짧은 작업으로 나누고 완료된 파일의 해시를 캐시합니다. 실행 시간 제한으로 중단된 단일 파일은 다시 검사하며 반복 중단은 사용자에게 알립니다.

## 이번 버전
1. 날짜 종류·영상 길이·용량·해상도·방향·폴더·형식·이름·즐겨찾기·보호 여부의 복합 필터와 안정적인 정렬.
2. 조건 프리셋 저장·적용·삭제 및 마지막 조건 유지.
3. 크기 후보 선별, SHA-256 완전 중복 그룹, 보호·즐겨찾기 제외 보존 추천.
4. 실제 저장 공간과 접근 가능한 사진·영상 통계, 대용량/오래된 화면 캡처 추천.
5. 썸네일·원본 열기·메타데이터·다중 선택·파일/폴더 보호.
6. 시스템 승인 휴지통 이동/복원. 이동 직전 상태 재검증, 500개 제한, 예상 용량과 실제 확보 용량 구분.
7. Android 13 미디어 권한 및 Android 14 선택 접근 구분. 권한 변경 후 재조회.
8. 회색 계열, 최소 장식, 큰 화면 목록/상세 배치, 접근성 이름과 상태 피드백.

## 데이터와 안전성
인터넷 권한, 서버, 계정, 광고·분석 SDK를 사용하지 않습니다. 백업은 꺼집니다. 보호 데이터는 분석 캐시와 별도로 보관합니다. 접근을 잃은 파일은 검사 결과에서 제거하며 해시 결과는 URI+크기+수정일+generation에 맞는 경우만 재사용합니다. 읽기 실패·불완전 해시는 중복으로 취급하지 않습니다. 보호 파일과 즐겨찾기는 삭제 선택/추천/최종 요청에서 제외합니다.

## 후속 범위
pHash 유사 사진, 다중 프레임 유사 영상, 클라우드 미디어, 전체 캐시 generation 증분 동기화, 매우 큰 단일 파일의 지속 가능한 포그라운드 검사, 실제 수만 파일/폴더블 성능 측정은 후속 범위입니다. 현재 버전에서 완료됐다고 표시하지 않습니다.

## 검증
필터와 중복 보존 정책/스트리밍 해시는 JVM 테스트, Android 빌드·lint는 Gradle로 검증합니다. 삭제 취소·권한 회수·선택 접근·휴지통 복원·백그라운드 복구는 에뮬레이터에서 확인하고, 실기기 대규모 성능과 제조사 휴지통 차이는 별도 검증으로 남깁니다.
