# GalliPick — 말랑한 추억 정리함

## 목적과 범위

사진과 동영상을 안전하게 정리하는 기존 앱을 둥글고 귀여운 하나의 시각 콘셉트로 꾸민다. 이번 요청의 둥근 형태와 생성 아이콘이 이전 회색·직각 시각 지침을 대체한다. 화면 이동, 복합 필터, 데이터 조회, 권한, 중복 검사, 보호 및 휴지통 정책은 기존 설계를 따른다.

## 콘셉트

크림색의 통통한 사진 카드 마스코트 **픽이**가 추억 정리를 돕는 작은 보관함이다. 세이지 민트, 따뜻한 종이색, 부드러운 복숭아색을 사용한다. 마스코트는 앱 헤더·홈·안내 및 빈 상태에 제한해 실제 사진과 파일 정보가 화면의 중심이 되게 한다. 필요한 설명과 삭제 확인을 귀여운 표현으로 흐리지 않는다.

| 역할 | 색상 | 사용 |
| --- | --- | --- |
| 배경 | `#FAF9F5` | 따뜻한 기본 바탕 |
| Ink | `#25483F` | 본문·제목·주요 조작 |
| Muted | `#597267` | 보조 설명·메타데이터 |
| Line | `#DCE6DF` | 부드러운 경계 |
| Panel | `#EEF4EE` | 정보 카드·보조 영역 |
| Mint | `#CDE6D8` | 선택 탭·강조 카드 |
| Peach | `#F5D6BD` | 작은 포인트 |

일반 크기의 본문과 설명은 배경 대비 **4.5:1 이상**을 유지한다. Muted는 대비 검토 후 더 진한 `#597267`로 조정했으며, 기본 배경에서 약 4.95:1, Panel에서 약 4.67:1이다. Mint·Peach 위의 글씨는 Ink를 우선한다. 흰색 글씨의 주요 버튼은 Ink 바탕을 사용한다.

## 형태와 화면

- 카드와 대화상자는 주로 16–24dp 모서리, 버튼·칩·탭은 둥근 형태로 통일한다. 입력란, 썸네일, 선택 상자, 드롭다운과 휴지통도 같은 형태를 따른다.
- 홈은 픽이와 짧은 소개, 저장공간, 사진/동영상 통계, 정리 시작 카드로 구성한다. 실제 수치와 기존 접근 범위 안내를 유지한다.
- 홈·파일·중복·정리·설정 탐색은 동일한 생성 아이콘 세트를 사용한다. 선택은 바탕과 라벨로도 구분하며 접근성 선택 의미를 유지한다.
- 파일/중복/휴지통의 선택·보호·비활성 상태가 분명해야 한다. 최소 48dp 주요 터치 영역과 기존 읽기 순서를 보존한다.
- 필터·정렬·상세·설정·빈 상태까지 같은 팔레트와 곡률을 적용한다. 기존 넓은 화면 배치, 스크롤과 고정 조작 영역을 보존한다.

## 이미지와 아이콘

생성 PNG는 모두 같은 크림·민트·복숭아 팔레트, 둥근 실루엣, 부드러운 입체감과 투명 배경을 사용한다. 별도의 바닥 그림자·글자·워터마크는 넣지 않는다.

| 생성 이미지 | 적용 의미 |
| --- | --- |
| `gp_mascot` | 픽이, 브랜드·홈·안내 및 런처 전경 원본 |
| `gp_home`, `gp_files`, `gp_duplicates`, `gp_cleanup`, `gp_settings` | 다섯 탐색 목적지 |
| `gp_photo`, `gp_video` | 미디어 통계·미리보기 없음·관련 빈 상태 |
| `gp_trash`, `gp_shield`, `gp_folder` | 휴지통·보호·보호 폴더 안내 |
| `gp_launcher_monochrome` | Android 테마 앱 아이콘용 단색 이미지 |

작은 조작 아이콘은 Material Rounded로 통일한다. 뒤로/앞으로, 확인, 닫기, 정보, 잠금, 외부 열기, 일시정지, 재생, 새로고침, 복원, 검색, 별, 필터 조절이 해당한다. 복원은 휴지통 아이콘과 구별되는 복원 화살표를 유지한다. 작은 보호 배지처럼 가독성이 우선인 곳은 Rounded 아이콘을 유지할 수 있다.

PNG는 `drawable-nodpi`에서 명시적 dp 크기로 표시하고 원래 색을 보존한다. `Image`를 쓰거나 색상 tint를 해제한다. 아이콘 내부 투명 여백을 정규화해 다섯 탐색 아이콘의 보이는 크기를 맞춘다. 밝고 어두운 바탕에서 투명 가장자리와 잘림을 확인한다. 적절한 내용 설명은 기존 클릭 가능한 부모가 제공하고 장식 이미지는 중복 낭독하지 않는다.

런처는 기존 adaptive icon 구조를 유지하고 민트 배경과 픽이 전경으로 바꾼다. 얼굴과 주요 실루엣을 마스크 안전 영역에 두고 원형·둥근 사각형에서 잘리지 않는지 확인한다. 앱 안의 아이콘과 런처가 동일한 픽이로 인식되어야 한다.

두 런처 전경은 비율형 여백 15%를 적용한다. 불투명도가 5를 넘는 픽셀의 최대 반경은 컬러 31.81dp, 단색 30.78dp로 33dp 안전 반경 안에 있다. Android의 비트맵 adaptive/단색 레이어와 비율형 inset을 사용한다. [플랫폼 기준](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive), [InsetDrawable](https://developer.android.com/reference/android/graphics/drawable/InsetDrawable).

## 유지할 동작과 검증

minSdk 30 / target·compileSdk 36, 로컬 처리 및 인터넷 권한 없음 정책을 유지한다. 즐겨찾기·보호 파일 제외, 남길 사본 재검증, 권한 변경 시 기존 목록 숨김, 시스템 휴지통 승인·복원, 영구 삭제 금지를 변경하지 않는다.

완료 기준은 기존 JVM 회귀 38개, `lintDebug`, `assembleDebug`, Android 16/API 36의 기존 통합 검사 4개 통과다. UI smoke에서 홈·파일·필터·중복·정리·설정 진입과 실제 홈/필터 화면을 확인한다. 대비, 선택/비활성 상태, 작은 아이콘의 구별, PNG 투명 가장자리, 런처 마스크, 긴 한글 문구와 스크롤을 시각 검토한다. 이번 변경의 실제 실행 결과와 기존 검증 기록을 구분해 기록한다.
