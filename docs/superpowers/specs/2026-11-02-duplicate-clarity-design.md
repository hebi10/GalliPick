# 중복 정리 구분

승인된 사용자 요청: 앞서 기획한 중복 영역 개선을 반영하고 GalliPick 소스·공개 릴리스·APK를 GitHub Actions를 통해 게시한다.

핵심 흐름은 남길 파일 확인 → 정리 후보 선택 → 선택 대상 검토 → Android 휴지통 승인이다. 선택만으로 이동하지 않는다. 기본은 후보 미선택이며 남길 파일·보호·즐겨찾기에는 선택 상자를 표시하지 않는다. 남김은 앱 추천/직접 지정/보호 이유를 표시하고 실제 근거 없이 원본·최고 화질로 표현하지 않는다.

묶음은 남길 파일을 먼저 표시하고 정리 후보와 구분한다. 보호 사본이 여러 개면 실제 남김 개수를 표시한다. 파일명·폴더·용량·영상 길이를 같은 위치에 둔다. 전체 선택은 현재 결과의 모든 묶음(스크롤 아래 포함)의 후보만 대상으로 하며 500개 제한을 실제 버튼 개수와 안내에 반영한다. 묶음 선택은 다른 묶음의 선택을 유지한다. 남길 파일 변경은 해당 묶음의 선택만 해제하며 이전 남김을 자동 선택하지 않는다.

선택이 있으면 하단에 개수·파일 용량·선택 해제·선택한 N개 휴지통 이동을 표시한다. 최종 검토에는 이동 대상과 남김을 함께 표시한다. 취소·승인·실패 결과는 실제 상태와 구분하고 이전 파일 버전/권한/보호/마지막 사본 검증을 유지한다.

비교는 역할을 표시한 A/B 두 사본으로 유지한다. 넓고 높은 창에서는 나란히, 좁거나 낮은 창에서는 전환과 제한된 스크롤을 사용한다. 남김 변경 때 패널을 재배치하지 않는다. 영상은 하나씩 재생하며 외부 파일 열기/화면 이탈 시 정리한다. 작은 화면과 큰 글꼴에서도 조작 접근을 유지한다.

기존 v0.1.5의 다크 테마·저장·한 줄 파일 도구·용량/길이 정렬·상단 스크롤 접힘·생성 브랜드 이미지를 유지한다. 작업 공간 정리로 원래 로컬 소스가 사라져 공개 v0.1.2와 전달 v0.1.5 APK의 동작을 기준으로 복원한다. 앱 전용 서명은 복구 파일의 공개 지문 d84aa7f6f6e402c4cf2722894f518042a223f143666c4bbf847f4c46ad3423f9를 고정하며 새 키를 생성하지 않는다. 새 앱은 com.hebi.gallipick, v0.1.6/code7이다.

릴리스는 검증한 정확한 소스 SHA를 기준으로 한다. 단위 검사·lint·Android 실행 검사 후 고정 키로 release APK를 서명하고 버전·패키지·인증서·체크섬을 확인한다. 개인 서명 키와 설정은 소스/공개 산출물에 포함하지 않는다. CI 비밀값 등록은 브라우저의 인증정보 취급 규칙을 적용한다. 기존 릴리스/태그를 덮어쓰지 않는다.
