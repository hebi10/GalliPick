# 사용성·안전성 보완

사용자 승인 범위: 2026-11-01의 전체 앱 피드백 기반 보완 요청. 기존 Kotlin/Compose, Android 11 이상, 로컬 처리, 픽이·크림/민트/복숭아 테마를 유지한다.

## 동작

- 필터·검색 조건 변경은 선택을 해제한다. 앱 복귀/수동 새로고침은 목록을 즉시 숨긴 뒤 현재 권한으로 재조회하고 URI와 fingerprint가 동일하며 보호되지 않은 선택만 복원한다. 선택 당시 버전을 보관해 변경된 파일은 요청에서 제외한다.
- 선택은 사진/중복/휴지통 모두 최대 500개. 모두 선택은 현재 조건의 앞 500개를 선택하고 제한을 안내한다. 확인창에는 파일명·폴더 목록을 제공한다. 시스템 승인과 사본 생존 확인을 유지한다.
- MediaStore 볼륨별 getVersion을 저장하고 변경 시 해당 해시를 무효화한다. 조회 오류는 빈 성공으로 바꾸지 않는다. 권한 축소는 안전하게 숨기며 조회 실패는 명확한 실패와 재시도를 표시한다.
- 파일별 체크포인트는 유지하되 중복 결과의 전체 재계산은 짧은 간격으로 합친다. 파일/해시 카탈로그는 공유해 중복 Room 관찰을 줄인다.
- 빠른 필터: 10분 이상 영상, 1GiB 이상, 1년 이전 영상. 0개 선택 시 삭제 패널을 숨기며 목록 스크롤 상태를 명시적으로 유지한다. 중복 화면에서 권한을 요청할 수 있게 한다.
- 중복 묶음에서 사용자가 보관 파일을 지정할 수 있다. 즐겨찾기/보호 파일은 계속 삭제 제외되며 마지막 사본은 유지한다.
- 앱 내부 사진 확대/이동, 영상 재생/일시정지/탐색을 제공한다. Android 기본 이미지 디코더와 VideoView를 사용하고 새 의존성은 추가하지 않는다. 외부 앱 열기도 유지한다. 미리보기는 리소스 크기·수명·오류를 제한하고 URI 변경/백그라운드/닫기 시 정리한다.

## 선택한 접근

선택 유지+숨은 선택 안내와 조건 변경 시 선택 해제 중 후자를 선택한다. 오삭제 위험과 복잡도를 줄이기 위해서다. 500개 자동 연속 삭제 대신 명시적인 500개 선택을 사용해 시스템 승인의 대상을 사용자가 알 수 있게 한다. 네이티브 미디어 API로 기존 구조 안에서 보완한다.

## 검증

선택 해제/복귀/변경 파일/500개 경계, 보관본 변경, 캐시 버전 변경, 오류 처리 회귀를 검증한다. 미디어가 채워진 Compose 테스트와 기존 단위/통합 테스트, lint, debug APK 빌드를 수행한다. 실기기·수만 파일 성능과 유사 이미지/영상 분석은 구현 완료로 주장하지 않는다.
