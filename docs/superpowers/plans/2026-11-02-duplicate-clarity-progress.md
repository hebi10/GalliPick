# 중복 정리 작업 기록

기준 원격: d48c396afca508051acfa6fbbde812b7517dbb96 (v0.1.2). 작업 브랜치 improve/duplicate-clarity-v0.1.6.

원래 로컬 v0.1.5 소스는 작업 공간 정리로 소실됐다. 공개 소스와 실제 전달 APK를 기준으로 기존 기능을 복원하며 이를 원래 커밋의 바이트 복구로 표현하지 않는다. v0.1.5 APK SHA-256은 45ea916bce6511e0fefab09ce47c7f49ae5d1d8bbf7f59fc89dc087677eb252e. 개인 서명 복구는 별도 비공개 경로에서 수행하며 공개 인증서만 추적한다.

구현: 테마·파일 도구·정렬·스크롤 헤더 복원, 중복 역할/개수/범위 표시, 묶음 선택과 남김 변경 정책, 창 크기에 맞춘 A/B 비교, 남김 사본 검토와 실제 처리 결과 확인 완료. 작은 창 영상 표시 영역과 재검증 중 창 닫기 경계도 반영했다. 독립 안전성·사용성·릴리스 검토에서 남은 P1/P2는 확인되지 않았다.

최종 로컬 빌드: Java17/Gradle8.13/SDK36, JVM82개 통과(실패/오류/건너뜀0), debug/release lint 오류0(경고17/15, hint각1), release APK와 Android 테스트 APK 생성 성공. Python 릴리스 검사18개 통과. 최종 Android 테스트 소스도 컴파일했으나 Android 실행은 GitHub API36 검사 대기다. 로컬 APK 메타데이터·고정 인증서 검증과 공개 대상130파일의 개인 키/비밀번호 누출 검사 통과.

게시: GitHub 공개 게시 권한은 사용자 메시지에 명시됨. 다음 단계는 검증 소스 원격 반영, API36 실행, main 병합, 공개 릴리스다. Actions의 서명 비밀값은 기존 키이며 공개 소스나 릴리스에 올리지 않는다. 브라우저 인증정보 규칙에 따라 필요한 확인/사용자 입력이 있으면 실제 단계에서 설명한다.
