# 중복 정리 작업 기록

기준 원격: d48c396afca508051acfa6fbbde812b7517dbb96 (v0.1.2). 작업 브랜치 improve/duplicate-clarity-v0.1.6.

원래 로컬 v0.1.5 소스는 작업 공간 정리로 소실됐다. 공개 소스와 실제 전달 APK를 기준으로 기존 기능을 복원하며 이를 원래 커밋의 바이트 복구로 표현하지 않는다. v0.1.5 APK SHA-256은 45ea916bce6511e0fefab09ce47c7f49ae5d1d8bbf7f59fc89dc087677eb252e. 개인 서명 복구는 별도 비공개 경로에서 수행하며 공개 인증서만 추적한다.

구현: 테마·파일 도구·정렬·스크롤 헤더 복원, 중복 역할/개수/범위 표시, 묶음 선택과 남김 변경 정책, 창 크기에 맞춘 A/B 비교, 남김 사본 검토와 실제 처리 결과 확인 완료. 작은 창 영상 표시 영역과 재검증 중 창 닫기 경계도 반영했다. 독립 안전성·사용성·릴리스 검토에서 남은 P1/P2는 확인되지 않았다.

최종 로컬 빌드: 안내 메시지 갱신 보완 뒤 34초에 성공했다. Java17/Gradle8.13/SDK36, JVM82개 통과(실패/오류/건너뜀0), debug/release lint 오류0(경고17/15, hint각1), release APK와 Android 테스트 APK 생성 성공. 릴리스 보조 도구의 앞선 Python 검사18개도 통과했다. 새 로컬 APK는 46,602,758 bytes, SHA-256 `fc19c2a1038e9f03ce9ce3bf42d354fc928ed7a33c6b0adc3c3cd72273264eb2`이며 v0.1.5와 같은 고정 인증서를 사용한다. 앞선 공개 대상130파일의 개인 키/비밀번호 누출 검사도 통과했다.

원격 반영: [PR #2](https://github.com/hebi10/GalliPick/pull/2)의 현재 검사 대상 head는 `62d5543a4744e9e27412e124cf9d422aca9e1400`, 기준 Git 트리는 `81eb568ac626ba6ea52a606050c2796751d42eff`다. 검사 대상 원격 소스와 로컬 제품·테스트 소스의 일치를 확인했다. 이 기록의 문서 보완은 제품·테스트 코드를 변경하지 않는다.
