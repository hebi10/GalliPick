# GalliPick 정밀 리디자인 4단계 — 파일 목록·필터

## 기준
- 레이아웃: Google Drive `GalliPick_9screens_design_reference_20261105.png`의 파일 목록·필터 화면
- 비교 기준: 3단계 `main` 커밋 `78905f5c76f3c0f5da4b2f1bbe4930d9b84358d6`
- 지원 기능 유지: 미디어 조건 검색, 정렬, 보호, 미디어 상세, Android 휴지통 승인, 필터 프리셋

## 화면 구조
- 파일 화면의 상단 헤더는 '파일' 제목을 사용하고 홈 등 다른 탭의 브랜드 헤더는 유지
- 검색창과 파일 종류 선택, 정렬·상세 필터·그리드/목록 전환을 분리
- 기본은 미디어 썸네일 중심의 3열에 가까운 적응형 그리드, 이름은 한 줄로 간결히 표시
- 목록 전환 시 파일명·용량·날짜를 표시하며 파일 상세 및 48dp 선택 터치 영역 유지
- 파일 수·총량과 전체 선택은 하단 요약에 표시하고 선택하면 안전한 휴지통 작업 바로 전환
- 필터는 여백 있는 중앙 카드 대신 전체 화면을 사용하는 페이지형 다이얼로그
- 기존 검색·파일 크기·길이·폴더·형식·해상도·방향·정렬·보호·즐겨찾기 조건과 날짜 직접 입력·달력·최근 기간 모두 유지
- 날짜 기간 바로가기 '이번 달', '지난 달' 추가, 필터 적용과 초기화/취소는 하단 고정

## 제외
- 실제 지원하지 않는 '기타' 파일 유형은 추가하지 않음
- 유사 사진 자동 검출·파일 영구 삭제·자동 정리 기능 추가하지 않음
- 파일 처리 도메인 로직·Play 서명키·versionCode·배포 트랙 변경하지 않음

## 검증
- Android 단위 테스트, Lint, 빌드
- 파일 선택·목록/그리드 전환·정렬·필터 조건과 프리셋 유지 검증
- 휴대폰 세로·가로·큰 글씨(160%), 태블릿 세로·가로 캡처
- 캡처 결과와 원본의 정보 위계·썸네일 가로폭·적용 버튼 위치 비교
