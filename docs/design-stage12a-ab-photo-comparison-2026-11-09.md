# GalliPick 12-A — A/B 사진 동시 비교

- 기준 브랜치: main, 기반 커밋 927d4cbbe249b881868eb9f9b278beaf4f0161bf
- 승인한 디자인: https://drive.google.com/drive/folders/13x0YR6hykKg4BTzkKLp80rnUxV8amc-n
- 관련 전체 기획: https://docs.google.com/document/d/1vMxGf3kUBTc5DAZX5-k2jm7hd67FGKyeKtJlPwC__2c/edit
- 범위: 12-A의 A/B 사진 두 장 미리보기와 확대 동기화·슬라이더 비교. 12-B의 자동 베스트컷 추천이나 12-C 검토함은 포함하지 않음

## 기능

1. 기존 유사 사진·연속 촬영·선명도 상세의 'A/B 비교'에서 진입. 기존 '한 장 보기'로 복귀 가능
2. 완전히 같은 파일 비교에서도 **사진이 두 장 이상일 때만** A/B 비교 허용. 동영상 단독 묶음에서는 기존 동영상 한 장 재생 유지
3. 묶음 썸네일을 눌러 A 또는 B 슬롯의 사진만 변경. 미리보기 전환/슬라이더 이동은 정리 후보 선택을 변경하지 않음
4. 나란히 / 슬라이더 비교 전환. 슬라이더로 오른쪽 B 사진의 표시 영역 이동
5. 두 사진 확대/이동 동기화 기본 활성. 끄면 개별 확대·이동, 화면 맞춤 및 확대/축소 버튼
6. URI·파일 수정 지문·볼륨 버전 기준으로 최대 2048px의 원본 미리보기 2개만 디코딩. 로딩 실패/권한 거부 시 재시도 및 실제 사진 데이터 미이동
7. 사진별 파일명·해상도·용량·촬영일/저장일을 함께 표시하고 개별 원본 열기 지원

## 보존 정책

- 유사/연속촬영 사진은 기존 SimilarPhotoReviewPolicy.allowed/maySelect가 선택 가능 여부, 보호·즐겨찾기·최소 한 장 보존을 판정
- 완전 중복은 기존 DuplicateRoles.candidateUris 및 남길 기준 파일 지정 콜백을 그대로 사용
- 실제 휴지통 이동은 기존 '선택한 사진 정리'와 Android 시스템 승인 경로에서만 실행
- 파일 보호, 임시 권한, 미디어 스냅샷 재검증과 관련된 기존 함수 시그니처/저장소 데이터 변경 없음
- Mono Cat 토큰·4개 탭·버전 v0.2.9/code20·Google Play/키/기능 외 자산 변경 없음
