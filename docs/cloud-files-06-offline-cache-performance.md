# CLOUD-FILES-06 — 오프라인·캐시·대량 파일 UX

선행 브랜치: `feature/cloud-files-05-verified-local-cloud-continuity`  
작업 브랜치: `feature/cloud-files-06-offline-cache-performance`

## 변경 의도

CloudFiles-01~05의 로컬+클라우드 통합 파일 목록을 기존 MediaStore 정리 흐름과 분리한 상태에서, 네트워크 장애·계정 변경·셀룰러 통신·대량 파일 수에 안전하게 대응합니다.

## 사용자에게 보이는 변화

1. 인터넷이 끊겨도 **앱이 살아 있는 동안 이미 불러온 해당 계정의 클라우드 목록 메타데이터**는 파일 탭에서 유지됩니다. 이전 목록임을 표시합니다.
2. **실제 사진·동영상 원본은 다운로드 없는 오프라인 재생을 지원하지 않습니다.** 오프라인일 때 원본 가져오기·동영상 재생 URL 발급을 멈추고 연결 안내를 표시합니다. 사용자 명시 요청에 따른 저장 파일은 기존 기기 파일로 이용합니다.
3. 네트워크가 재연결되면 계정·카탈로그 조회가 다시 시도됩니다. 네트워크 조회 오류는 로컬 파일 목록을 지우지 않습니다.
4. 모바일 데이터 등 요금제 종량 연결에서는 자동 **클라우드 사진 썸네일 불러오기를 기본 제한**합니다. 사용자는 그 화면에서만 `이번 화면에서 허용`을 눌러 목록 썸네일 다운로드를 켤 수 있습니다. 직접 선택한 사진/동영상 열람은 사용자가 요청한 네트워크 동작입니다.
5. 통합 파일 목록은 **90개/페이지**로 분리하여 필요할 때 `다음 파일 보기`로 확장합니다. 로컬 미디어 카탈로그와 실제 휴지통/선택 데이터는 이 렌더링 제한에 의해 삭제되지 않습니다.
6. 서버 목록을 불러오지 못했을 때 기존 클라우드 보관함의 **같은 UID 세션에 남아 있는** 목록을 유지합니다.

## 개인정보·캐시 수명

- 사진 썸네일은 최대 12MiB의 앱 내부 **메모리 LRU**에 보관됩니다. 앱 재시작 후에는 보존하지 않습니다.
- UID가 변경되면 이전 계정의 메모리 캐시가 제거됩니다. 이전 계정의 지연된 썸네일 작업이 새 계정 캐시를 되돌리거나 지우지 못하도록 소유자 검사를 추가했습니다.
- 클라우드 파일 목록은 해당 UID로 로그인하여 읽은 Compose 메모리 상태만 사용합니다. 원본의 URL·Google 인증 토큰·목록 전체를 SharedPreferences, MediaStore 또는 파일 디스크 캐시에 저장하지 않습니다.
- 앱 프로세스가 종료됐다가 오프라인에서 다시 켜진 경우 **클라우드 목록은 보장하지 않습니다.** 그때는 인터넷에 다시 연결해야 보관함을 읽을 수 있습니다.
- 기존 다운로드/복원, 파일 삭제 요청 및 서버 원본 삭제 정책은 변경하지 않았습니다.

## 네트워크 경계

- `ConnectivityManager`의 현재 기본 네트워크가 INTERNET + VALIDATED를 충족해야 온라인으로 봅니다.
- NET_CAPABILITY_NOT_METERED가 없는 연결은 썸네일 자동 다운로드를 제한합니다.
- 네트워크 상태 관찰은 `DisposableEffect`의 하나의 수명 주기 콜백으로 수행하며 닫힐 때 해제합니다. 새로운 광고 또는 외부 분석 SDK를 추가하지 않았습니다.
- Cloud 프로필에만 `ACCESS_NETWORK_STATE` 권한을 선언합니다.
- 사진 전체 화면/동영상 스트리밍은 오프라인에서 자동 네트워크 시도를 하지 않습니다. 동영상은 네트워크 전환 시 기존 플레이어와 단기 URL을 해제합니다.

## 성능·미해결 범위

- 클라이언트의 렌더링만 90개씩 나눕니다. 현재 클라우드 시험 백엔드는 **계정당 최대 250개 파일, 파일당 64MiB** 제한을 그대로 유지합니다.
- 서버 측 커서 기반 페이징, CDN 썸네일 전용 객체, 오프라인 원본 동영상 캐시, 암호화된 재시작 후 보관함 캐시는 **이번 PR에 포함하지 않습니다**.
- 이미 서버 목록에 들어온 항목의 검색·필터·정렬은 전 범위에서 실행하고, 화면 렌더링에 전달하는 목록만 페이지 크기로 제한합니다.
- SHA-256 대조의 `최대 6개·96MiB` 실행 제한과 명시적 다음 비교 흐름을 유지합니다.
