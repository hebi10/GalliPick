# GalliPick 정밀 리디자인 3단계 — 홈 화면

- 기준 시안: `GalliPick_9screens_design_reference_20261105.png` 첫 번째 화면
- 선행 작업: PR #24 (공통 디자인 시스템), PR #25 (홈·파일·정리·설정 4개 탭)
- 수정 범위: 홈 화면과 해당 회귀 테스트, Android 캡처 워크플로
- 기존 파일 삭제/복원, SHA-256 판정, 보호 규칙, Android 권한 승인 로직 변경 없음

## 원본과의 정합성

| 대상 | 이전 구조 | 3단계 구조 |
|---|---|---|
| 환영 영역 | 우측 작은 고양이·좌측 안내·큰 배너 | 좌측 큰 캐릭터·우측 핵심 메시지와 정리 시작 버튼 |
| 저장공간 | 빠른 정리 뒤의 큰 정보 카드 | 캐릭터 아래에 기기 사용량/전체 용량 및 진행률만 간결히 표시 |
| 메인 바로가기 | 세로형 중복/정리 목록 + 별도 사진/영상 통계 | 시안 순서 2×2: 사진·영상 정리 / 중복 파일 찾기 / 용량 큰 파일 / 오래된 파일 |
| 태블릿 | 별도 액션/통계 2열 | 저장공간 왼쪽·2×2 바로가기 오른쪽, 창 너비 기반 |
| 접근성 | 기존 내용 중심 | 글씨 확대 시 1열 카드, 역할/전체 터치 영역 유지 |

## 실제 동작

- `정리 시작하기`: 기존 정리 후보 탭
- `사진·영상 정리`: 파일 화면의 전체 필터 (자동 정리 아님)
- `중복 파일 찾기`: 기존 정리 하위 화면의 SHA-256 완전 중복 검사
- `용량 큰 파일`: 100 MiB 이상으로 필터링하고 용량 큰 순 정렬
- `오래된 파일`: 촬영 날짜 기준 1년 이상 된 항목을 오래된 순으로 조회
- 기기 저장공간 사용률은 기기 전체 용량과 여유 용량으로 계산하며, 접근 가능한 미디어 합계나 자동 삭제 예상치가 아님
- 접근 권한 없을 때는 기존 선택 권한 요청을 보존하며, 부분 접근 상태에서는 선택된 미디어 수만 표시

## 검증 기준

- Android 단위 테스트, Lint, Assemble
- `ReferenceHomeScreenTest`: 4개 타일과 CTA 실제 이동, 필터값, 기기 저장공간 수치, 권한 요청
- `AdaptiveOverviewTest`: 좁은/넓은 화면과 160% 글씨 및 핵심 CTA
- `ReferenceNavigationFlowTest`: 홈 중복 카드 → 정리 하위 화면 → 뒤로 가기
- Android 실제 홈 캡처: 휴대폰 세로·가로·큰 글씨, 태블릿 세로·가로
- 최종적으로 원본 시안과 실제 캡처를 비교하고 오류 발생 시 PR 병합 전 수정

스토어 서명키·버전 코드·Google Play 트랙 변경 없음. 디자인 시안의 예시 저장공간 수치는 앱에 고정값으로 삽입하지 않음.
