# GalliPick 9-A — 정리 탭 · 폴더별 용량 분석

작성일: 2026-11-08 / 기존 기준: v0.2.7 (code 18), main 1663b98d8a552759ed24342a448f2c59b8c6019d

## 구현 범위

1. 홈·파일·정리·설정 4개 최상위 탭 유지.
2. 정리 탭 상단을 '정리' 제목·설명·기존 고양이 일러스트로 보정. 짧거나 큰 글씨 환경에서 일러스트 생략.
3. '사진 비교' 섹션에서 기존 완전히 같은 파일 찾기(SHA-256)를 그대로 연결. 하단 '종류별 정리'에 기존 5개 후보 항목 그대로 유지.
4. '폴더별 용량 분석'을 기존 정리 카테고리 뒤에 배치. 누르면 신규 하위 화면으로 이동. 뒤로가기는 정리 탭으로 복귀.
5. 폴더별 용량은 접근 가능한 **사진·영상만**, 휴지통 상태 파일 제외. URI 중복 제거, 경로별로 직접 속한 파일만 한 번씩 합산. 하위 폴더를 부모에 중복 포함하지 않음.
6. 요약: 접근 가능 파일 수·폴더 수·용량; 폴더 목록: 경로, 파일 수, 합계, 전체 접근 가능 미디어 대비 비율.
7. 정렬: 용량 큰 순·작은 순·파일 많은 순. 폴더 탭 시 현재 경로만 표시하는 기존 파일 탭 필터로 이동. 경로 없는 파일은 합계에 포함하되 탐색 버튼으로 제공하지 않음.
8. 접근 거부/부분 접근/카탈로그 실패/로딩/빈 목록에 안전한 설명. 파일 선택, 보호, 즐겨찾기 및 기존 시스템 휴지통 승인·복원 흐름 무변경.

## UI 기준

- 기존 `AppTheme.kt` 라이트/다크 팔레트·GalliUiMetrics 사용
- 외부 마스코트 이미지는 기존 `gp_cat_organize` 재사용. 새로운 이미지·그라데이션·그림자 미추가
- 정리 화면: 앱 헤더 아래 제목·설명 → 사진 비교 → 종류별 정리 → 확인 안내
- 폴더 화면: 뒤로가기·제목 → 현재 접근 가능 사진/영상 합계 → 정렬 → 폴더별 결과
- 48dp 이상 기본 터치 영역, 긴 폴더 경로 두 줄 말줄임, 기기 가로·세로 대응
- 용량 표시는 파일 크기 합계일 뿐 정리 가능 크기·실제 확보 공간이 아님

## 제외 범위

유사 사진 pHash·연속 촬영·선명도 측정은 9-B~9-E, 정리 기록은 9-F에서 별도로 구현. 아직 동작하지 않는 기능은 클릭 가능한 항목으로 노출하지 않음. 앱 ID, 서명, 버전 코드, Google Play 등록정보·테스트 트랙, 프로젝트 외 코드는 변경하지 않음.

## 검증 계획 및 완료 기준

- JVM: 파일별 URI 중복, 하위 경로 분리, 보호·즐겨찾기 포함/휴지통 제외, 잘못된 경로, 0바이트 및 합계 오버플로.
- Compose: 정리 탭 신규 구조, 기존 중복 진입·기존 5개 정리 후보의 동작, 폴더 진입·뒤로가기, 폴더 집계·정렬·특정 경로 필터, 접근 거부·빈 목록.
- Android: `testDebugUnitTest lintDebug assembleDebug`, `connectedDebugAndroidTest`, 휴대폰 세로/가로/글씨 160% 및 태블릿 세로/가로 화면 검수.
- 통과한 PR만 `main` 병합. 배포는 별도 요청 시 실행.

## 남은 9단계

- 9-B: 사진 분석 홈·상태·pHash 기반 로컬 유사사진 분석 엔진, 별도 캐시/DB 마이그레이션, 워커 취소·재개.
- 9-C: 유사사진 묶음·비교·다중 보관·수동 선택·Android 휴지통 연동, 보호 파일/변경 파일 안전 검증.
- 9-D: 시간/유사도를 이용한 연속 촬영 그룹화 및 상세 비교.
- 9-E: 축소 이미지 선명도 추정 및 오탐지 안내, 자동 정리 금지.
- 9-F: 확인된 휴지통 이동·복원 결과의 로컬 정리 이력, 이력만 삭제하는 기능.
- 9-G: 5개 Android 화면 환경·실기기 UX·회귀·기존 시안 비교와 단계별 안전 병합, 별도 배포 결정.
