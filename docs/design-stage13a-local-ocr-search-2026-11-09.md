# GalliPick 13-A — 로컬 사진 속 글자 검색(OCR)

기준: 12-C main 병합 `2d159d1`, Mono Cat, 기존 4탭. GalliPick v0.2.9 / code20 유지.

## 목적
기존 파일명·폴더 검색은 유지하면서, 사용자 선택으로 사진 속 한국어·영문 텍스트를 로컬에서 인식해 검색한다. OCR 분석은 정리 후보/실제 휴지통 이동과 완전히 별개다.

## 화면·탐색
- 파일 > 검색창 아래 검색 범위 선택: **파일명·폴더 / 사진 속 글자** 두 모드. 13-B 사진 내용 검색은 이후 단계다.
- 기본은 종전 파일명·폴더 모드. 기존 검색 조건·정렬·미디어 종류·보기 전환·보호·즐겨찾기·파일 상세 행동은 보존.
- 글자 검색은 별도 검색어를 사용하며 이미 접근 가능하고 유효하게 색인된 사진만 보여 준다. 사진 그리드/목록에 글자 일치 부분을 간략히 표시하고 원본 미리보기/상세는 종전 조작을 사용한다.
- 로컬 OCR 상단 패널: 현재 허용된 사진 수, 정상/실패 색인 건수, 실행 상태·진행률, 사용자 **시작 / 일시정지 / 재개 / 재시도**.
- 빈 입력/0건/미분석/권한 일부·전체 거부/분석 실패 상태에서 완전 분석 완료라고 오인하지 않는 문구를 제공한다.
- 설정 > 사진 글자 검색 데이터 > 확인창 > 글자 색인만 초기화. 원본과 기존 분석·보호/휴지통 기록 불변.

## 인식 엔진
- Google ML Kit Text Recognition v2의 **앱 번들 한국어+라틴 문자 모델** `16.0.1`을 사용한다.
- 처리 대상은 MediaStore를 통해 현재 접근 가능한 사진이다. 영상, 휴지통 사진, 임의 서버 업로드 제외.
- ImageDecoder의 소프트웨어 비트맵을 최대 긴 변 2048픽셀로 줄여 두 언어 인식을 실행한다.
- WorkManager의 고유 작업과 Room 토큰을 사용해 진행 상황, 90초 예산 후 이어서 분석, 일시정지, 실패 재시도를 구현한다.
- 결과는 기기 내 Room에 한 사진당 최대 20,000자까지 저장하며, UI는 검색 일치 일부만 표시한다.

## 권한·무결성
- Room v7→v8: `photo_ocr_index`, `photo_ocr_session` 별도 테이블. 명시적 마이그레이션.
- 동일 URI, fingerprint, volumeVersion(기기 미디어 볼륨 버전)을 확인한 결과만 검색 노출한다. 권한 철회·사진 삭제·수정·볼륨 변경 시 색인을 차단/무효화한다.
- 접근 가능한 미디어 교체가 완료되는 트랜잭션에서 삭제/변경된 OCR 기록을 prune한다.
- 읽기/디코딩 실패는 FAIL 상태로 표시하고 검색 결과로 다루지 않는다. 빈 글자 사진은 NO_TEXT로 기록한다.
- 자동 선택·자동 휴지통 이동/영구 삭제·비밀 클라우드 전송·새 상위 탭 없음.
- 기존 앱 ID, 플레이 트랙, 기존 서명키, versionName/versionCode 미변경. 신규 Play 배포 없음.
