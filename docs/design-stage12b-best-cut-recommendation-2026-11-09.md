# 12-B — 베스트 컷 자동 추천

기준: `12-A` 병합된 `main` (`fd24c184`), 앱 `v0.2.9 / code 20`.
수정 범위: 유사 사진·연속 촬영 결과/상세, 기존 로컬 사진 분석 결과, 품질 캐시, 검증 코드. 새로운 모델 다운로드·네트워크 분석·신규 상위 탭·Play 배포 없음.

## 동작
- 기존 128×128 로컬 샘플의 선명도 추정값 외에 평균 밝기와 암부/명부 극단값에 근거한 **노출 참고값**을 저장한다.
- 같은 묶음에서 **선명도(55%) / 원본 해상도(25%) / 노출 참고값(20%)**을 상대 비교한다. 차이가 작거나 데이터가 불충분하면 **판단 보류**. 비율은 공인 품질 점수가 아니라 설명 가능한 보수적 휴리스틱이다.
- 추천된 사진은 결과 목록에 이름·이유를 표시하고 비교 화면에서 이유를 펼쳐 볼 수 있다. 기존 A/B·단일 미리보기 전환 및 화면 세로 스크롤 하나 유지.
- 추천 사진이 정리 후보에 선택돼 있다면 재확인 안내를 표시한다.
- 모델 미설치나 서버 업로드 없이 기존 사진 분석 WorkManager를 사용한다. 기존 캐시는 스키마 5→6 마이그레이션 뒤 노출 정보가 없는 사진만 재분석할 수 있다.

## 보존·제한
- 추천은 **사진 자동 선택·남김 지정·휴지통 이동·삭제**를 유발하지 않는다. 최종 선택·보호 폴더·즐겨찾기·최소 한 장 보존 및 Android 시스템 휴지통 승인 정책은 기존과 동일하다.
- 선명도·노출은 축소 샘플 추정치일 뿐 카메라 노출값 또는 미적 완성도의 객관적 측정이 아니다. 역광, 야경, 의도적 저조도·아웃포커스 등에서는 틀릴 수 있다.
- 불명확한 캐시/디코딩 실패/파일 변경/권한 상실/지표 동점에서는 추천을 보류한다. 캐시 fingerprint와 volumeVersion 검증은 그대로 유지한다.
- 신규 의존성 없음. 앱 ID, 트랙, 서명키, versionName/versionCode 미변경.

## 확인 항목
1. JVM: 노출 힌트, 최고 화질 선택·동점·분석 부족·순서 안정성.
2. Android 계측: Room 노출 캐시 저장·무효화, 추천 이유 펼치기만으로 정리 후보가 변경되지 않음.
3. 기존 12-A A/B 비교, 유사 사진/연속 촬영·선명도, 원본 보기, 단일 스크롤, 데이터 보존 전체 회귀.
4. Android verification, device tests 및 5화면 프로필 × 라이트/다크 10환경 실제 캡처.
5. 실패/경고 해결 후에만 `main` 병합. 별도 새 Google Play 제출은 다음 승인 릴리스에서 시행.
