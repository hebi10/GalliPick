# CLOUD-03 원본 복원 시험

디버그 빌드의 클라우드 탭에서 현재 Google 계정에 속한 검증 완료 원본을 조회한다. 시험 계정당 최대 250개가 표시된다. 복원 요청은 2분짜리 다운로드 URL을 발급받으며, URL로 지정한 객체 세대와 저장된 SHA-256·바이트 수가 일치한 원본만 기기에 공개한다.

## 개발 프로젝트 확인

`gallipick-dev`에 `listBackups`와 `getBackupDownload`를 배포한 뒤 승인된 개발 계정과 합성 미디어로 확인한다. 두 계정의 원본 목록이 서로 분리되는지 검증하고, 파일 하나를 올린 뒤 원본 SHA-256을 기록해 다른 테스트 기기에서 받은 파일과 비교한다. 복원 중 네트워크 끊김·로그아웃·파일 크기 또는 SHA-256 불일치가 발생하면 미완료 이미지나 동영상이 갤러리에 나타나지 않아야 한다.

| 검증 | 기대 결과 |
|---|---|
| 계정 A와 B에서 각각 목록 조회 | 현재 계정의 검증 완료 항목만 표시 |
| 파일명 충돌 또는 같은 파일의 수동 복원 | Android가 새 항목을 만들고 기존 파일은 보존 |
| 다운로드 URL 만료 또는 객체 세대 변경 | 검증 가능한 정확한 객체의 다운로드 권한을 다시 요청 |
| 손상 바이트, 부족한 용량, 다운로드 중 취소 | 기기 파일 공개 차단. 완료 메시지 미표시 |
| 계정 변경 후 이전 사용자 파일 응답 도착 | 이전 계정의 작업과 화면 상태 해제 |
