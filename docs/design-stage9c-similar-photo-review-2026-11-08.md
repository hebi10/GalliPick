# GalliPick 9-C — 유사 사진 결과·가로 비교·다중 보관·휴지통 연결

2026-11-08 / 기준: 9-B main `03d73919dbc75a12e63864eef11e735fc5287bb7`.

## 주요 기능
- Room `photo_perceptual_hash`의 유효한 pHash만 참조. 사진의 URI, fingerprint, 볼륨 버전과 접근 가능한 MediaStore 목록이 동일한 경우에만 화면에 표시.
- 지각 해시 해밍 거리 6 이하, 가로세로 비율 차이 12% 이하 후보를 보수적으로 묶음. 8개의 8-bit 밴드 색인으로 유사 후보를 줄이고 **그룹 전체 구성원이 서로 기준을 만족하는 경우에만** 합류. 다른 장면도 유사한 해시가 나올 수 있으므로 ‘후보’로만 표시.
- 기존 정리 > 비슷한 사진 찾기 > 사진 분석 완료 > 결과 보기 > 사진 묶음 > 가로 비교. 하단 내비게이션 홈·파일·정리·설정 4개 유지.
- 실제 MediaThumbnail을 가로 리스트에 사용. 사진 탭은 큰 미리보기만 전환. 사용자 정리 후보 선택은 별도 버튼이며 초기값은 **선택 없음**.
- 유사 사진은 모든 사진이 처음에 ‘남김’ 상태. 여러 장을 남길 수 있고, 직접 선택한 정리 후보만 휴지통 검토에 포함.
- 각 그룹에 최소 한 장 보관 규칙. 보호·즐겨찾기·보호 폴더의 사진은 선택 불가. 전체 선택 상한 500건.
- 기존 MainActivity.Android MediaStore.createTrashRequest 승인과 결과 검증을 사용. 검토 전에 그리고 실제 Android 승인 직전에도 본래 pHash·URI·fingerprint·볼륨 버전과 남아 있는 사본을 확인. 검증 실패 시 이동 차단. 유사 사진이 실제로 같은 파일이라고 주장하지 않음.
- 기존 SHA-256 완전 중복, 파일 보호, 권한 제한, 설정, 휴지통 복원 기능 유지. 사진 원본은 서버로 전송하지 않음.

## UI
- `SimilarPhotoResultsScreen.kt`: 결과 총 묶음·총 사진 수·썸네일 가로 스트립·수동 비교 진입·선택 사진 검토.
- `SimilarPhotoCompareScreen.kt`: 가로 스트립의 현재 포커스, 선택 사진 큰 미리보기, 이름/용량/해상도/촬영일/폴더, 정리 후보 선택 및 해제, 외부 사진 열기.
- `PhotoAnalysisScreen.kt`: 9-B 완료 화면의 결과 보기 버튼. 0묶음은 결과 없음 안내.
- 반응형: 작은 휴대폰 세로는 세로 스크롤, 넓은 화면은 미리보기·상세 정보를 좌우 배치. 라이트·다크는 기존 테마 토큰만 사용.
- 앱 선택만으로 삭제/이동하지 않으며, 최종 Android 확인을 유지.

## QA
- JVM: 유사 해시 그룹화, 해밍 거리/비율, transitive chain 차단, URI 정렬·중복 배제, 최대 한 장 생존 규칙, 즐겨찾기·폴더 보호.
- Android Compose: 그룹 가로 썸네일, 수동 후보 선택/취소, 다중 남김, 실제 목록을 누르지 않고 휴지통 이동하지 않음.
- Android device tests와 verification 통과만 `main` 병합. 필요하면 에뮬레이터 캡처 보강.
- Play 비공개 테스트 배포·버전 변경은 이번 작업 범위가 아님.
