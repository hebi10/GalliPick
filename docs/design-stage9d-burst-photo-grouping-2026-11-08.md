# GalliPick 9-D — 연속 촬영 사진 그룹화·비교

기준: 9-C가 반영된 `main` 커밋 `8bd12131c385afa6dcf21f4ad6434751cb012175`.

## 목적

9-B의 기기 내 pHash 분석 결과와 MediaStore 촬영 시각을 활용해 짧은 간격으로 촬영한 **비슷한 장면의 사진 후보**를 묶습니다. 촬영 시각만 같다고 중복 처리하지 않으며, 사진을 자동 삭제하지 않습니다.

## 그룹화 규칙

1. 사진(PHOTO), 휴지통 밖, 정상 크기, 유효한 16자 pHash, **`dateTakenMs > 0`**만 포함합니다. `dateAddedMs` 또는 파일 수정일로 촬영 시각을 대신하지 않습니다.
2. 촬영 시각이 인접한 두 사진 사이 간격 **5,000ms 이내**, 동일 묶음 전체 촬영 구간 **30,000ms 이내**, 한 묶음 **최대 64장**으로 제한합니다.
3. 모든 묶음 구성원 간 pHash 해밍 거리 **6 이내** 및 가로세로 비율 차이 **12% 이내**를 요구합니다. 연결고리가 하나 있다고 전혀 다른 장면까지 합치는 transitive 병합을 허용하지 않습니다.
4. 기존 유사 사진 결과와 구별되는 `burst:` 접두 ID. 사진은 촬영 시각순·URI 순으로 안정 정렬하고, 묶음은 최근 촬영일 우선 표시합니다.
5. 이미 9-C에서 검증한 pHash 캐시·fingerprint·볼륨 버전만 사용하고 별도 서버, 새 의존성, 데이터베이스 구조 변경은 없습니다.
6. 알고리즘은 유사 촬영 장면의 **추천 후보**만 제시하며 원본·가장 좋은 사진 여부를 자동 판정하지 않습니다.

## UI

- 정리 > 비슷한 사진 찾기 > 사진 분석이 완료된 경우에 ‘연속 촬영’ 결과 요약을 표시.
- `BurstPhotoResultsScreen`: 촬영 시각·묶음 사진 수·용량과 실제 가로 썸네일. 비슷한 사진 결과 화면의 디자인 토큰 재사용.
- 기존 `SimilarPhotoCompareScreen`을 연속 촬영 모드로 재사용. 고해상도 미리보기, 남길 사진 여러 장 선택, 개별 ‘정리 후보 선택’, 보호·즐겨찾기 제외.
- 각 묶음 최소 한 장 보관. 후보 선택 후 기존 Android 휴지통 확인·권한 승인을 반드시 거침.
- 유사 사진과 연속 촬영의 선택은 이동/뒤로가기로 초기화해 서로 다른 분석 모드를 혼합하지 않음. 기존 홈·파일·정리·설정 4탭 유지.
- 촬영 시각이 없는 사진은 연속 촬영 후보에서 제외. 결과가 없으면 이유를 설명하며 임의의 그룹 수를 표시하지 않음.

## 안전성 검증

- 기존 `SimilarPhotoReviewPolicy`와 `MediaRepository.confirmedSimilarSurvivor` 재사용: 휴지통 확인과 시스템 승인 직전에 캐시·정체성·남길 사본 상태를 검증합니다.
- 새 알고리즘의 그룹을 먼저 검증받아야 하며, 화면에서 단순히 이미지를 누르는 것만으로 삭제 대상이 되지 않습니다.
- 사용자 선택 한도 500건, Android 휴지통 이동 승인·복원 정책을 변경하지 않습니다.
- JVM 테스트: 5초 경계·30초 범위·시간 미상·서로 다른 장면·가로세로 비율 차이·중간 연결고리 방지·최신 묶음 정렬·휴지통/동영상 제외.
- Android Compose 테스트: 촬영시각 표시·빈 상태 안내·실제 썸네일 비교 진입·다중 보관·마지막 한 장 이동 방지.
- `Android verification` + `Android device tests` 통과한 최종 PR만 `main` 병합. 출시/배포·버전 변경은 이번 범위가 아님.
